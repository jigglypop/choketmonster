# Town trainers

`trainer-red.glb` and `trainer-green.glb` are web copies of `public/models/trainer/red.glb` and `green.glb`,
which the project owner supplied. Reduced with glTF-Transform: the colour texture resized to 1024 px as WebP,
the normal and metallic-roughness maps removed for a matte finish, the clips renamed to `idle`, `walk` and
`run` (`restpose` dropped), resampled, and meshes Draco-compressed.
