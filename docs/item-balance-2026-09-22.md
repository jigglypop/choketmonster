# 물품 조정

기존 회복·성장·진화 물품과 배틀 장착 도구의 구매 및 사용 경로를 연결한다. 원작 전체 아이템을 새로 수록하는 패치는 아니다.

- 상처약은 20HP / 300원, 좋은상처약은 60HP / 700원. 월드·일반전에서 둘을 직접 선택하고 팀 상세에서도 전투 밖 회복에 사용한다.
- 아름다움 간식은 +20, 애정 간식은 +1. 현재 수치와 재고, 최대 사용 수량에 맞는 입력을 제공한다. 기존 친밀도 UI 제거 정책은 유지한다.
- 진화의돌 3,000원 및 교환 진화 도구 4,000원은 유지한다. 특수진화 캡슐은 8,000원이다.
- 먹다남은음식·기합의띠는 각 4,000원, 구애 도구 3종은 각 6,000원, 생명의구슬은 8,000원이다. 효과 수치는 유지한다. 기합의띠는 전투별 1회 사용이며 영구 파괴하지 않는다.
- 장착은 가방 재고 1개를 사용하고 해제·교체·합치기·놓아주기는 해당 도구를 가방으로 반환한다. 보유한 포켓몬의 기존 장착은 유지하며 구형 세이브에 없던 가방 키만 0으로 초기화한다. 거래 시 도구는 개체와 함께 이동한다.
- 상점은 물품 분류와 수량 구매를 지원한다. 프렌들리숍은 탐험 패널에 복구하지 않는다.

검증: 아이템·합치기·저장 단위 테스트, Rust 가방 검증, 모바일 구매→장착 교체→간식→회복→재로드, 상처약 재고가 없는 실제 월드 전투의 좋은상처약 사용을 검사한다. 실제 배포 여부는 CI 결과와 운영 버전 응답으로 별도 확인한다.
