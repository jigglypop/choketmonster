## 조건

플레이어 몸은 레벨 35 이상해풀로 고정하고, 상대는 12종 중 시드에 따라 선택한 레벨 35 포켓몬이다. 이 몸·배틀은 벤치마크용 초기 조건이며 사용자 저장에 지급하지 않는다. 게임 엔진의 실제 피해·PP·상태·턴 순서를 실행한다. 상대는 매번 새로 초기화한 고정 커넥톰 정책으로 움직인다.

회로 초기화 시드는 43, 137, 281이다. 각각 18개 학습 에피소드 후 가중치를 고정하고, 학습에 사용하지 않은 같은 6개 평가 시드(900000–900005)에서 비교했다. 최대 100턴이며 타임아웃은 별도로 집계한다. 무작위 정책은 기술 네 슬롯과 대기에서 선택하고, 규칙 정책은 공개된 능력치·타입에서 계산한 예상 피해가 가장 큰 기술을 고른다. 사용 불가능한 슬롯의 보정은 모든 정책에서 같다.

보상은 준 피해의 HP 비율에서 받은 피해의 HP 비율과 턴 비용 0.015를 뺀 값이며, 승리 +1/패배 -1을 추가한다. 학습은 출력층만 바꾼다. 해부학적 연결·감각 투영은 고정한다.

## 2026-09-12 로컬 Rust 전체 그래프 제한 기술 학습

`npx tsx scripts/experiment-local-moves.ts`로 로그인 없이 로컬 Rust의 `/api/local-brains/step-batch`를 직접 호출했다. 서버 응답에서 확인한 회로는 `malecns-v1.0-curated-neurons166700-csr-ad0ab3a8e6eaebe7`, 뉴런 166,700개, 엣지 25,582,938개였다. 뇌 초기화 seed 43과 137마다 6개 학습 에피소드를 실행했고, 별도의 공통 평가 seed 4개에서 최대 24턴으로 학습 전 동결 정책과 학습 후 동결 정책을 비교했다.

기술 슬롯은 공격 `화염방사`, 버프 `칼춤`, 회복 `HP회복`, 상태 `독가루`로 고정했다. 무작위·학습 전·학습 후 정책 모두 `automatedMoveMask`를 적용했다. 평가에서는 `learning: false`를 사용했고, 2개 뇌 × 2개 정책 × 4개 seed의 16회 평가에서 update 수가 바뀌지 않았다. 학습으로 update 수는 seed 43에서 0→18, seed 137에서 0→28로 변했다.

| 정책 | 승리 / 평가 | 평균 누적 보상 |
| --- | ---: | ---: |
| 무작위 | 1 / 4 | -0.2166 |
| 학습 전 동결 | 2 / 8 | -0.2572 |
| 학습 후 동결 | 2 / 8 | -0.2959 |

승수는 같고 평균 누적 보상은 낮아졌으므로, 이 제한 fixture에서는 전투 학습 개선을 주장하지 않는다. 정책별 독립 반복 단위가 뇌 seed 2개뿐이어서 일반화할 수도 없다.

첫 요청은 전체 체크포인트로 상태를 복원하고 이후 103개 요청은 `checkpointId`만 보내는 warm path를 사용했다. 이번 실행에는 428 cache miss가 없었지만, 스크립트는 각 단계의 최신 전체 체크포인트를 메모리에 유지해 428 응답 시 같은 요청을 한 번 복구한다. 같은 초기 체크포인트와 평가 seed에서 다시 실행한 3프레임 action trace는 완전히 같았고 SHA-256은 `57967e64b65908051813cb66d315b0fc4669c17901a822ad0f545af9393ba749`였다.

원자료는 `artifacts/local-moves-2026-09-12T10-54-45-430Z/`의 `report.json`, `replay.json`, `checkpoints.json`에 저장했다. 감각 입력, 행동 마스크, 보상, 출력 학습은 게임에서 설계한 요소다. 이 결과는 전체 커넥톰 그래프가 계산에 쓰였다는 실행 증거이며 생물학적 학습의 증거는 아니다.
