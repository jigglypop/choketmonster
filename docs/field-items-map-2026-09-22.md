# 필드 도구와 탐색 지도

- 장착 도구 47종과 지원되는 메가진화석 64종은 필드 획득·플레이어 금전 거래로만 얻는다. 도구 목록·등급·출처는 `held-items-2026-09-23.md`를 따른다. 회복약과 진화 도구 구매는 유지한다.
- 각 지방의 통행 가능한 길가에 최대 3개를 배치한다. 수거한 슬롯은 실제 플레이 시간 30분 후 다시 생성하며 대기 시간과 획득 횟수를 저장한다. 새로고침으로 초기화되지 않는다. 종류 선택은 도구 75%, 메가진화석 25%를 기본으로 하며 해당 지방에 가능한 종류가 없으면 다른 종류를 사용한다. 도구는 등급 가중치(일반 4 · 고급 2 · 희귀 1)로 고른다.
- 지정 포켓몬을 실제 포획한 경우만 보상을 추첨한다. 도구는 등급별 15% · 8% · 4%, 메가진화석은 대응하는 기본 종 포획 시 총 4%이며 여러 메가 모습이 있으면 균등 분배한다. 한 번에 최대 1개를 지급한다. 단순 처치에는 지급하지 않는다.
- 도구 출처는 `held-items-2026-09-23.md`의 목록에 있다.
- 팀·박스 상세에서 획득처를 펼쳐 볼 수 있다. 지도에서 장소·포켓몬·도구를 검색하고 해당 장소의 포획 확률과 길가 획득 가능 도구를 확인할 수 있다.
- 지도에는 실제 지형의 높낮이·물·숲·산·눈·사막을 표시한다. 마을·동굴·도구·미방문 필터, 선택 지점 길찾기, 현재 길가 물품 표시를 제공한다.
- 10개 지방의 도로 옆에 지역별 색상의 한글 이정표, 쉼터, 전망대와 다리 난간을 배치한다. 반복 기둥은 인스턴싱하고 가까운 시설만 렌더링한다.

## 검증

단위 검사에서 111종 획득처, 10개 지방의 통행 가능한 배치, 포획 보상, 저장·재시작 중복 획득 방지, 테라스탈 저장 마이그레이션을 확인한다. 브라우저에서는 실제 WebGPU 길가 물품·시설, 줍기·장착·새로고침, 지도 검색·길찾기·모바일 표시와 기존 저장 시작을 확인한다. Linux 배포 CI는 저장 검증과 랭크 엔진의 데이터베이스 비의존 검사를 실행한다.

시작 화면은 로그인 성공 전 게임 모듈을 불러오지 않는다. 초켓몬스터 이미지와 로그인 폼을 먼저 표시하고 성공 후 회로·3D 월드의 실제 준비 상태를 표시한다. 로그인 실패·계정 서버 오류·로그아웃 시 플레이를 차단하며 세션 만료 시 재인증 전까지 정지한다.
