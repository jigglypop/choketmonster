# 2026-09-15 이동·표시 개선

사람형 필드 NPC를 제거하고 기존 처치 기록과 진행 중인 배틀의 저장 호환성은 유지했다. 처음 높였던 기본 이동 속도는 사용자의 요청에 따라 다시 약 31% 낮춰 종족 속도식의 2.4배로 맞췄다. 포켓몬 표시 크기는 원래보다 35% 작다. 자동 모드에서 추적 대상이 없으면 통행 가능한 탐험 목적지를 감각 입력으로 제공한다. 회로의 이동 선택과 개체별 기억은 유지한다. 제한 비교와 재현 근거는 [실험 문서](experiments.md#2026-09-15-필드-이동-변경)에 있다.

밤낮 조명 전환, 안개, 풀·잎의 추가 바람 효과를 제거했다. 그림자와 수면 효과는 유지한다. 그림자는 PC 512px·15Hz·24m 범위, 모바일 256px·10Hz·16m 범위로 제한한다. 수면은 물가와의 거리에 따라 상세 파도·물가 효과와 단순 재질을 전환한다. PC는 40m 진입/52m 이탈, 모바일은 24m 진입/34m 이탈로 경계를 달리해 깜빡임을 줄인다.

## 끊김 원인과 수정

풀·흙의 원래 텍스처를 복원하고 모든 지형 조각이 하나의 텍스처 묶음과 재질을 공유하게 했다. 지형이 이동 거리 경계에서 생성·제거돼도 공유 재질을 폐기하거나 새로 컴파일하지 않는다. 텍스처는 기본 mipmap 필터링을 유지한다.

- 변하는 조명 값을 생성자 인수로 넘겨 조명이 재생성되고 WebGPU 재질이 반복 컴파일되던 경로를 제거했다.
- 이동 거리 경계에서 지형 메시를 다른 물리 래퍼로 감싸며 다시 생성하던 경로를 제거했다. 통행 판정은 기존 시뮬레이션 지형·경로 검사를 유지한다.
- 보이는 소품 수가 바뀔 때 인스턴스 GPU 버퍼를 새로 만들던 경로를 고정 용량 재사용으로 바꿨다.
- 이동 입력에서 전체 HUD 갱신을 최대 10Hz로 제한했다. 카메라와 직접 이동은 매 프레임 처리한다.

## 실행 근거

로컬 Windows의 headed Chrome/WebGPU, Vite 개발 서버, 실제 포켓몬 모델로 측정했다. 인증·저장 API는 고정 fixture다. 렌더링 측정이며 운영 서버 응답 속도나 모든 모바일 기기의 FPS를 나타내지 않는다.

| 시나리오 | 프레임 중간값 | p95 | 비고 |
| --- | ---: | ---: | --- |
| 이전 배포, 변화하는 오전 조명, 정지 | 418.0ms | 1,026.9ms | `baseline-fixed-surface` |
| 최종 그림자·수면 LOD, 관동 이동 | 16.7ms | 28.7ms | `release-shadow-lod-desktop-water`, 582프레임 |
| 같은 설정, 모바일 화면·터치 환경, 관동 이동 | 16.7ms | 28.1ms | `release-shadow-lod-mobile-water`, 596프레임 |
| 텍스처 복원·공유 재질·속도 완화, PC | 16.7ms | 31.6ms | `textured-shared-desktop-water`, 582프레임 |
| 텍스처 복원·공유 재질·속도 완화, 모바일 화면 | 16.7ms | 22.7ms | `textured-shared-mobile-water`, 603프레임 |

이전 배포와 최종본은 정지/이동과 지역 조건이 다르므로 같은 장면의 개선 배수로 해석하지 않는다. 최종 PC 이동 기록은 10초 전체 프레임을 수집했으며 p99 45.2ms, 최대 78.7ms, DPR 0.8, 페이지 오류 0건이었다. 모바일은 p99 38.4ms, 최대 55.8ms였다. 조명 객체 유지, 안개 없음, 주간 밝기 고정, 그림자 켜짐과 예산, 상세/단순 수면 재질 공존도 확인했다. 원자료와 스크린샷은 `artifacts/world-speed/`에 보존한다.

핵심 동작 관련 38개 검사와 수면 LOD를 포함한 추가 관련 9개 검사가 통과했다. 속도 완화·텍스처 복원 뒤 관련 20개 검사를 통과했다. 최종 재질은 모든 지형 조각이 한 개를 공유하고 이동 전후 같은 객체를 유지했다. 실제 브라우저 동굴 표시와 모바일 HUD 검사도 통과했다. 오디오는 후속 요청에 따라 파일 기반 재생으로 교체했다. 모바일 검사는 Chrome의 터치·화면 에뮬레이션이며 실물 iPhone/Safari 검증은 아니다.

재실행: 터미널에서 `pnpm dev`를 실행한 뒤 `WORLD_MOVING=1`, `WORLD_WARMUP_MS=15000` 환경 변수와 함께 `pnpm exec tsx scripts/measure-world-runtime.ts <새 결과 이름> water`를 실행한다. 탐험 비교는 `scripts/compare-world-exploration.ts`를 사용한다.
