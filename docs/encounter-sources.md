# 지역 출현표와 일반 트레이너 출처

야생 출현 원본은 PokeAPI 데이터 저장소의 커밋 `8fe210b21c9abbe73de93670f3d5a346c80a3625`로 고정한다. 원본 CSV의 SHA-256은 `data/local/johto-gold-source/<commit>/manifest.json`과 생성 코드의 `REGIONAL_ENCOUNTER_SOURCE`에 기록했다. `npx tsx scripts/generate-regional-encounters.ts`로 다시 생성할 수 있다.

공개 원본의 장소별 출현 종 수를 같은 기준으로 비교했다. 현재 3D 월드와 대응하는 동일 장소에서 걷기와 파도타기 종을 비교했다. 관동 후보는 Red 78종, Yellow 73종, FireRed 67종, LeafGreen 66종이므로 Red를 고정했다. 성도 후보는 Gold 86종, Crystal 100종, HeartGold 94종, SoulSilver 94종이므로 Crystal을 고정했다. 전체 원본 지역을 단순 합산하면 Sevii 제도처럼 현재 월드에 없는 장소가 섞이므로 버전 선택 근거로 쓰지 않았다. 런타임은 실제 3D 지형에서 걷기와 파도타기만 사용하며 현재 장소, 시간대, 지형에 맞지 않는 방법으로 대체하지 않는다. 예외적으로 Crystal의 용의 굴은 원본에 파도타기 표만 있고 현재 동굴 장면은 단일 바위 바닥이므로, 그 장소에 한해서 원본 파도타기 표를 동굴 생성표로 연결한다. Red에는 시간대 차이가 없으므로 세 시간대에 같은 원본 표를 쓴다.

현재 월드 장소와 걷기/파도타기 경로로 연결되는 원본 종은 관동 78종, 성도 100종이다. 원본 표와 별도로 각 지역 도감 전체를 `supplemental` 희귀 규칙으로 제공한다. 관동 151종은 18개 장소, 성도 251종은 18개 장소에 진행도와 서식 지형을 따라 분산했다. 초반 도로, 숲, 수면, 여러 동굴과 후반 지역을 사용하며 전설·환상종은 배지 8개와 높은 레벨을 요구한다. 관동 전설은 발전소·쌍둥이섬·챔피언로드·블루시티 동굴, 성도 전설은 소용돌이섬·방울탑·은빛산에 배치한다. 스타팅 포켓몬은 배지 4개 이후 재방문 때부터 희귀하게 나타난다.

보완 규칙은 같은 장소·시간대·지형의 20번째 생성에서만 순환한다. 일반 생성은 Red/Crystal 원본의 종과 슬롯 가중치를 사용한다. 실제 전투 레벨은 캠페인 진행과 지역 난이도에 맞춘 `regionalWildLevels` 범위로 정규화한다. `tests/spawn-reachability.test.ts`는 각 규칙마다 실제 atlas 또는 `CAVE_SCENES`에서 막히지 않은 정확한 지형 좌표를 찾고 `OpenWorldSimulation.spawnWildAt` 경로를 호출하여 관동 151종과 성도 251종이 모두 실제 생성되는지 검사한다. 모델 경로도 관동 151/151, 성도 251/251을 별도로 확인했다.

희귀도 지수는 고정 분포를 비교하기 위한 게임 내부 지수다. 실제 플레이에서 관측한 확률 통계가 아니다. 원본 걷기/파도타기 슬롯과 `supplemental` 5% 주기 몫을 합치고, 아침 6시간·낮 10시간·밤 8시간으로 가중하며 초원·숲·수면·바위 지형을 모두 포함한다. 중복 개체 합치기 값은 이 지수를 사용한다.

하루는 공유 가능한 20분 주기로 계산한다. 04~10시는 아침, 10~20시는 낮, 나머지는 밤이다. 저장에는 주기 위치를 기록하며 서버 시각을 받은 클라이언트는 `synchronizeWorldClock(epochMilliseconds)`로 같은 위상에 맞춘다.

성도 일반 트레이너의 파티와 위치는 pret의 Pokemon Crystal 영어 어셈블리 커밋 `7a7881d0d62e0ddbd82dcf10e7116807487ac651`에서 파싱했다. `scripts/generate-johto-trainers.ts`는 전체 지도 스크립트의 트레이너 오브젝트와 파티를 연결해 원본 트레이너 176명을 34개 월드 장소에 배치한다. 원본 트레이너가 없는 진행 장소 13곳에는 원본 파티를 재사용한 `supplemental` 배치를 명시해, 총 189명을 47개 장소에서 만날 수 있다. pret 저장소에는 별도 라이선스 선언이 없으므로 공개 배포 전 권리 범위를 다시 검토해야 한다. Crystal 트레이너 자료와 Crystal 야생 출현표는 서로 다른 출처임을 화면과 코드에서 구분한다.
