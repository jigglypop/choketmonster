# 재질·물가와 포니대협곡 시련 수정

## 포니대협곡 진행

대협곡은 8번째 시련이지만 입장 조건도 인증 8개여서 완료 전 접근할 수 없었다. 대협곡 요구치만 7개로 바꾸고, 이후 라나키라마운틴과 알로라리그의 8개 조건은 유지했다. 기존 저장 형식과 서버 코드는 변경하지 않는다.

7개 인증으로 진입·도전·전투 저장 복원을 검사했다. 실제 브라우저에서는 대협곡 도착 저장을 불러와 지도 안내의 7/8 인증과 시련 이름을 확인하고 도전 버튼으로 전투 1턴을 시작했다. 장거리 도보 전체를 자동 재생한 검사는 아니다. 실제 GLB 로드와 프레임 진행, 페이지·렌더 오류 없음도 확인했다.

## 광택과 각진 표현

- GLB 971개, 재질 2,956개, 메시 4,948개를 검사했다. 금속맵 없이 금속값이 1인 재질 135개와 법선 없는 메시 399개를 발견했다.
- 비금속 생물 표면의 과도한 금속값과 낮은 거칠기를 런타임에서 보정한다. 강철 타입, 명시된 금속 재질과 금속맵은 보존하며 눈·유리 같은 의도된 광택은 구분한다. 이름과 타입을 사용하는 보정이므로 모든 자산의 작가 의도를 확정한 판정은 아니다.
- 누락된 법선만 생성한다. 메시 연결, UV, 스킨 가중치, 모프와 원본 GLB 파일을 바꾸지 않는다. 모험뿐 아니라 팀·도감·기존 전투 모델에도 같은 보정을 적용한다.
- 바위·나무 cute-nature 9개 자산의 22개 메시, 11,098개 삼각형은 이미 부드러운 법선이며 이음새 오류가 없었다. 남는 실루엣의 각은 원본 저폴리 형태다. 불필요한 전체 세분화나 법선 재작성은 하지 않는다.
- 주변 소품의 복사된 재질도 공통 비금속·거친 표면 보정을 거치며, 땅·바위의 PBR 거칠기 하한을 높여 젖은 플라스틱 같은 반사를 줄인다.

## 물가

삼각형 중심만 보고 땅과 물 재질을 통째로 바꾸던 방식을 없앴다. 실제 지역 sampler의 물 경계를 이용해 해안 거리장을 만들고 땅·젖은 모래·얕은 물·깊은 물을 혼합한다. 주변 물에는 서로 다른 방향의 작은 물결, 약한 거품과 반사를 넣고 먼 물에서는 상세 효과를 생략한다. 기존 허가된 물결·풀·흙 텍스처를 재사용한다.

해안이 걸친 지형 조각만 근거리에서 더 잘게 나누며, 나머지는 기존 LOD를 사용한다. 재질·텍스처는 공유하고, 지형 생성 중 샘플을 캐시한다. 지형 높이·충돌·통행 판정과 이동 속도는 그대로 유지한다. 지형 조각 경계에서 동일한 이웃 높이로 법선을 계산하여 조명 이음새를 줄이고, 경계 가림막의 서로 반대인 삼각형이 법선을 상쇄하던 문제와 수면의 검은 이음선도 수정했다.

## 실행 근거와 범위

- 관련 단위 검사: 27개 통과.
- TypeScript 검사와 프로덕션 빌드 통과.
- 실제 UI 시련 시작: 1개 시나리오 통과.
- 실제 성도 분노의호수 GLB·텍스처를 불러온 PC·모바일 화면 확인. 셰이더 오류·자산 요청 실패 0.
- 물가 높이 보존, 해안 필드 범위, 서로 다른 LOD 경계의 법선 일치 검사.
- 자료: `artifacts/material-audit/`, `artifacts/scenery-normals/`, `artifacts/shoreline-review/`.
- 재현: 터미널 `pnpm dev` 실행 후 `pnpm exec tsx scripts/capture-shoreline.ts`, `pnpm exec playwright test tests/ui/alola-final-trial.spec.ts`.

브라우저 렌더 검사는 headless WebGL2 fallback에서 수행했다. 물가 처리의 실기기 WebGPU FPS 개선을 주장하지 않는다. 모든 지역·모델을 눈으로 개별 검수한 것은 아니며, 저폴리 실루엣 자체를 제거하려면 해당 모델을 더 세밀한 기하로 교체해야 한다.
