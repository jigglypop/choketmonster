# 자동 변신 설정

팀·박스 상세의 `자동 변신`에서 메가진화 모습 또는 테라 타입을 고른다. 설정하지 않은 개체는 기존 동작을 유지한다. 선택은 개체와 함께 저장되며 전투·포획 중에는 변경할 수 없다.

- 야생전, 체육관, 트레이너전, 랭크전의 첫 출전과 교체 즉시 적용한다. 변신 버튼을 누르거나 한 턴을 기다릴 필요가 없다.
- 기절 후 교체도 같은 규칙을 사용한다. 배틀당 메가진화 1회와 테라스탈 1회의 기존 제한을 유지한다. 이미 변신한 개체를 다시 내면 변신 상태를 유지한다.
- 한 개체에는 메가진화 또는 테라스탈 하나를 설정한다. 진화 후 호환되지 않는 메가진화 설정은 해제하고 테라 타입은 유지한다.
- 검증된 3D 모델이 없는 메가진화 33종은 설정 목록에서 제외하며 클라이언트·저장 API·랭크 엔진에서 거부한다.
- 구형 저장에는 설정을 추가하지 않는다. 기존 가방·개체·경험치·회로 기억을 유지한다.

검증 경로: `tests/automatic-transformations.test.ts`, Rust `preferred` 테스트, 브라우저 `automatic-transformations.spec.ts`·`world-combat-forms.spec.ts`·`ranked-forms.spec.ts`. 브라우저 검증에는 설정 저장과 새로고침, 실제 WebGPU 메가 모델·테라 왕관 표시, 로컬 PostgreSQL 기반 두 계정의 랭크전 첫 턴 자동 변신이 포함된다. 배포 완료 여부는 CI와 운영 버전 응답으로 별도 확인한다.
