# 메가진화 설정

팀·박스 상세의 `메가진화`에서 사용할 모습을 고른다. 대응하는 메가진화석이 필요하다. 설정은 개체와 함께 저장되며 필드에서도 해당 3D 모습으로 표시된다. 전투·포획 중에는 설정을 변경할 수 없다.

- 야생전, 체육관, 트레이너전, 랭크전의 첫 출전과 교체 즉시 적용한다. 변신 버튼을 누르거나 한 턴을 기다릴 필요가 없다.
- 기절 후 교체도 같은 규칙을 사용한다. 배틀당 메가진화 1회 제한을 유지한다. 이미 변신한 개체를 다시 내면 변신 상태를 유지한다.
- 진화 후 호환되지 않는 메가진화 설정은 해제한다.
- 검증된 3D 모델이 없는 메가진화 33종은 설정 목록에서 제외하며 클라이언트·저장 API·랭크 엔진에서 거부한다.
- 테라스탈은 제거했다. 구형 저장의 테라 설정과 활성 변신만 정리하며 개체·HP·경험치·남은 PP·회로 기억·전투 진행은 유지한다. 랭크전의 기존 테라 타입도 원래 타입으로 복원한다.

검증 경로: `tests/automatic-transformations.test.ts`, `tests/removed-tera.test.ts`, Rust `ranked::tests`, 브라우저 `automatic-transformations.spec.ts`·`world-combat-forms.spec.ts`. 브라우저에서는 설정 저장·새로고침과 실제 WebGPU 메가·알로라 모델을 확인한다. 배포 완료 여부는 CI와 운영 버전 응답으로 별도 확인한다.
