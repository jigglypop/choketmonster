# 2026-09-16 지역 확장과 플레이 개선

## 실행

`pnpm dev --port 5173 --strictPort`로 실행한다. 로컬 주소는 http://127.0.0.1:5173/ 이다.
이번 작업은 로컬 구현과 검증이며 운영 배포는 수행하지 않았다.

## 플레이 변경

- 리그 건물은 지방별 외형과 색을 사용하며 도착 지점을 가리지 않도록 통행로 밖에 배치한다.
- 지방·지형별 타일 색을 구분한다. 풀·흙 텍스처, 그림자와 수면 효과를 유지한다.
- 초파리 길잡이와 바닥 표시, 상단 목적지 카드, 미니맵 경로로 다음 체육관·리그를 안내한다. 동굴 안에서는 내부 출구 좌표를 사용한다.
- 체육관 입구에 권장 레벨과 배지 순서에 따른 잠금을 표시한다.
- 포켓몬 표시 크기를 18% 늘린다. 이동 속도와 시뮬레이션 난수는 바꾸지 않는다.
- 동굴에 굴곡진 돌 바닥, 외곽 암벽, 종유석·석순·물웅덩이를 추가한다. 중앙 통로와 입출구를 유지한다.
- 저장에 야생 개체와 재출현 대기가 합쳐 12마리 미만이면 기존 데이터를 먼저 검증하고 12마리까지 보충한다. 기존 개체와 회로 상태를 보존하며 18마리 초과 등의 손상 검사는 유지한다.
- 중복 합치기는 보내는 개체 레벨 합계의 20%를 한 번 내림해 적용한다. 예: 레벨 12와 20을 보내면 +6레벨이다. 남기는 개체의 경험치 진행률과 기억을 유지하고 Lv.100을 넘지 않는다.
- 경험치 공유가 켜져 있으면 살아 있는 팀원 모두에게 같은 전투 경험치를 준다. 자동 야생 전투는 건강한 팀원을 순환 출전시키며 순서를 저장한다.
- 이상한사탕은 팀 상세 화면에서 수량과 예상 레벨을 확인하고 한 번에 먹인다. 정수 수량·보유량·Lv.100을 확인한 뒤 일괄 적용한다. 오류가 나면 일부만 소비하지 않는다.

## 호연 → 신오 → 하나

관동 리그 완료 후 호연, 호연 리그 완료 후 신오, 신오 리그 완료 후 하나로 여행한다. 각 지방에 체육관 8곳과 사천왕·챔피언 5연전을 연결했다.

도시와 도로 연결을 근거로 자체 지형·충돌·건물 배치·도착 좌표를 작성했다. 지도 이미지를 입체 지형으로 간주하지 않는다. 과거 `hoenn/sinnoh/unova-atlas-v1/v2` 저장은 이전 지도에서 좌표를 검증하고 새 지도로 옮긴다. 아직 여행 조건을 충족하지 않은 과거 확장 저장은 시작 지방으로 돌아가며 소유 개체·회로·수집 기록을 보존한다.

출현표는 PokeAPI revision `8fe210b21c9abbe73de93670f3d5a346c80a3625`의 에메랄드·플래티넘·블랙으로 고정했다. 지원하는 도보·수면 출현의 종 다양성을 비교했으며 블랙/화이트 동률에서는 블랙을 선택했다. 하나 계절 표는 봄으로 고정한다. 시간별 원본 가중치를 보존하고 원본에서 빠지는 해당 세대 종은 `supplemental` 희귀 분포로 추가한다. 도감에서도 원본과 추가 분포를 구분한다.

## 모델과 리깅 근거

- 원본: https://github.com/Pokemon-3D-api/assets/tree/429de1288cea0d43f5b4f56305d2276e94239d65
- 다운로드 범위: 전국도감 252–649, 398개 GLB, 35,311,044바이트.
- 로컬 원본: `data/local/pokemon-models-expanded/429de1288cea0d43f5b4f56305d2276e94239d65/`
- 기하·파일별 SHA-256: `artifacts/research/region-expansion/model-audit.json`
- 브라우저 골격·가중치·동작 검사: `artifacts/research/region-expansion/rig-verification.json`, 398/398 통과.
- 원본 클립이 있는 23종은 `artifacts/research/region-expansion/native-animation-verification-selected.json`에서 별도로 재검증했다. 매 클립의 13개 포즈를 검사했고 22종은 원본 스킨 변형이 확인됐다. 테오키스(#386)는 원본 402개 트랙이 모두 정적이어서 원본 클립을 보존하고 자체 동작 4개를 추가했다. 최종 23/23 통과이며 단순 모델 전체 이동은 스킨 변형으로 세지 않는다.
- 기존 골격이나 동작이 부족하면 `regional-authored-v2`로 자체 골격·스킨 가중치와 idle/walk/attack/damage 동작을 추가한다. 자체 제작 동작을 원본 동작이라고 표시하지 않는다.
- 실제 렌더 육안 확인은 세 지방 스타터 9종의 대표 포즈이다. 398종 전체의 모든 포즈를 개별 미술 검수했다는 의미는 아니다.
- `521-M.glb`처럼 성별 접미사가 있는 실제 소스 URL에도 동일한 리깅 경로를 적용한다.
- 저장소 MIT 표기가 포켓몬 모델의 재배포 권리를 증명하지는 않는다. 로컬 원본과 검증 자료를 보관하며 빌드는 기존 방식대로 고정된 공개 소스 URL을 참조한다. 모델 원본을 배포 폴더에 복제하지 않는다.

지도·출현·모델 출처 상세는 `artifacts/research/region-expansion/sources.json`에 남겼다. 재생성 스크립트는 `scripts/fetch-expansion-encounter-source.ts`, `scripts/generate-expansion-encounters.ts`, `scripts/audit-expansion-models.ts`, `scripts/verify-expansion-rigging.ts`이다.

## 검증 범위

- 24개 체육관과 15개 리그 전투를 실제 전투 엔진 턴으로 진행하고 저장·복원을 확인했다.
- 지도 연결, 지형 높이 연속성, 충돌, 안전 도착, 출현 가중치, 전체 추가 종의 원본/희귀 분포, 구형 지도 저장을 검사했다.
- 로그인 시 짧은 야생 목록 복원, 단건/일괄 합치기, 이상한사탕 3개 일괄 사용과 새로고침 유지, 기본 MP4 재생과 사용자 MP4 복원을 브라우저에서 확인했다.
- 호연·신오·하나 브라우저 시나리오 3개는 체육관 전투 시작 및 저장 복원 후 실제 스타터와 건물 GLB까지 로드된 화면을 확인했다. 캡처는 `artifacts/expansion-runtime/`에 있다.
- 모바일 목적지 카드의 터치 가능 위치, 희귀 추가 분포 도감, 이상한사탕 일괄 사용을 확인했다. `artifacts/expansion-mobile/guide.png`, `candy.png`에 최종 화면을 보관했다.
- Rust 전체 검사 38/38과 프론트엔드 production build를 통과했다.
- 원본 모델 파일 검사, 리깅 검사, 게임 통합 화면 검사는 서로 별도 근거다. 서버 단위 검사는 운영 서버에 배포됐다는 증거가 아니다.
- 기존 대형 번들 경고는 남아 있다. 시각 변경으로 신경 회로의 생물학적 학습 성능이 검증됐다고 주장하지 않는다.
