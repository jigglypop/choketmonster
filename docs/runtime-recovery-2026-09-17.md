# 로컬 게임플레이 수정과 검증 · 2026-09-17

이 기록은 작업 트리의 로컬 구현·실행 결과다. 배포 완료나 원본 자산의 재배포 권리 확보를 뜻하지 않는다.

## 모델 로딩과 연결 복구

- 기존 `data-ready`는 렌더러 초기화만 뜻했다. 이제 렌더러와 파트너·전투 상대의 실제 모델 준비가 모두 완료되어야 켜진다. 렌더러만의 상태는 `data-renderer-ready`로 분리했다.
- 플레이 패널은 모델 준비 검사를 필수로 사용한다. 아직 확인되지 않은 모델, 로딩 중 모델, 실패한 모델은 이동·접촉 전투에서 제외한다. 수동 입력과 서버 전투 턴에도 같은 검사를 적용한다.
- 화면 밖으로 나가거나 종이 교체되는 것을 모델 성공으로 취급하지 않는다. 늦게 도착한 이전 종의 콜백도 새 종을 준비 완료로 바꾸지 못한다.
- 공유 캐시의 실패 대기 60초를 명시적 재시도로 해제한다. 45초 넘게 끝나지 않는 로딩은 실패로 표시하고 늦은 결과는 폐기한다. 다른 화면이 사용하는 정상 모델을 강제로 삭제하지 않는다.
- 접힌 설정과 별개로 재개·모델 재시도 버튼을 표시한다. 서버 요청 실패는 같은 턴/요청 ID로 재시도하며 대기 중인 회로 최종 기록을 버리거나 부분 회로로 몰래 전환하지 않는다.

## 함께 정리한 내용

- 트레이너 랭크전 UI, 전설·환상 제외/허용 두 리그, 등급 이름 테두리, 매칭·행동·항복·완료 후 순위 복귀. 요청 중 중복 제출·리그 변경과 이전 응답의 화면 덮어쓰기를 방지한다.
- 팀·박스 상세의 상처약 사용/수량 표시 제거, 접힌 진화 UI, 친밀도 자연 진화·간식 판매 제거. 과거 저장 필드는 유지한다.
- 기존 작업 트리의 산·눈·사막 지형, 동굴 출구 버튼과 검색 안정성 변경을 통합 확인했다. 신오 산지의 과도한 높이 차로 연결 도로가 막히는 부분을 낮췄다.
- 가라르·히스이·팔데아 선택지와 진행·저장 검증을 연결했다. 지역별 대표 모델 로딩, 지도 도보 이동, 정지 후 저장·새로고침 복원을 브라우저에서 검사했다.
- 사용하지 않는 옛 월드 배치/재출현 함수 3개, 중복 공격 판별 함수, 미사용 UI 변수·임포트를 제거했다. 지형 샘플 타입도 한 정의로 통합했다. 저장 호환성용 코드는 일괄 삭제하지 않았다.

## 검증 범위

- 전체 Vitest: 앞선 통합 시점 71개 파일 / 379개 테스트 통과. 최신 모델 게이트·정리 뒤 관련 6개 파일 / 35개 테스트 통과.
- Rust 저장 검증 22개 통과.
- Rust 랭크전 7개 통과. 로컬 PostgreSQL의 분리된 SQLx 테스트 DB에서 두 계정의 두 리그 매칭·승패·레이팅까지 검사했다.
- 브라우저: 모델 실패→재시도→실제 GLB 표시, 로딩 지연 중 수동 입력 차단, 랭크전 기본 흐름, 동굴 입출구, 검색, 지형, 진화 화면 통과. 후기 지방은 가라르·히스이·팔데아의 대표 모델과 이동·저장 복원을 확인했다.
- 서버 장애 → 재시도 실패 → 연결 복구 → 동일 요청 ID 재시도 → 다음 전투 턴의 브라우저 흐름도 통과했다. 이 검사는 모의 API를 사용하므로 실제 배포 서버 장애 복구·두 사용자 브라우저 간 실전 대전과는 구분한다.
- `npm run build` 통과. 기존 대형 번들 경고는 남아 있다.
- 로컬 프론트엔드 `pnpm dev`(5187)와 Rust API(8080)를 터미널에서 실행했다. PostgreSQL과 166,700개 뉴런 회로 로딩을 확인했다. 운영 배포는 수행하지 않았다.

## 남은 경계

- 기본 종 1,025개가 기존 런타임 카탈로그에 연결되어 있지만, 원본 라이선스·텍스처 경계와 전 종의 인게임 미관 검증은 별개다. 54개 HOME 보완 모델은 기존의 외부 URL 전략을 유지하며 새 자산을 배포 디렉터리에 복사하지 않았다.
- 알로라·히스이 변종을 기본 모습 모델로 대체해 완료라고 표시하지 않는다. 메가 모델 조사 결과도 실제 메가진화 전투 구현 완료가 아니다.
- 메가진화와 모든 특수 기술의 전용 규칙·연출은 아직 완료되지 않았다. 모델/리깅 근거는 기존 전 세대 준비 기록과 로컬 연구 산출물을 참고한다.
