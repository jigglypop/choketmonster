# 화면 설정

헤더의 슬라이더 아이콘 **화면 설정**에서 변경한다. 변경 즉시 미리보기와 게임 화면에 적용되고, 별도 IndexedDB `choketmon-interface`의 `preferences` 저장소에 기록된다. 새로고침·계정 전환 후에도 같은 기기의 설정을 유지한다. 게임 저장과 분리되어 PostgreSQL에는 보내지 않는다. 저장 실패는 설정 창 안에 표시한다.

| 항목 | 선택 |
| --- | --- |
| 글자 크기 | 기본의 100~150%, 5% 단위 |
| 정보 간격 | 여유롭게 / 촘촘하게 |
| 전투 패널 위치 | 오른쪽 / 왼쪽 / 아래 가운데 |
| 팀 상세 배치 | 박스 옆에 / 넓게 한 열로 |
| 패널 대비 | 기본 / 높게 |

좁은 화면에서는 전투 패널을 하단에, 팀 상세를 한 열로 배치한다. 패널 위치 선택은 넓은 화면에서 적용한다. 탐험 조작은 제목을 눌러 접을 수 있다. 긴 패널은 내부 스크롤과 둥근 스크롤 손잡이를 사용하고, 팀 상세는 모바일에서 페이지와 함께 스크롤한다. 기술 선택 입력은 모바일 확대를 피할 수 있는 최소 16px을 유지한다.

**기본값으로**는 화면 설정만 초기화한다. 게임 진행, 포켓몬, 기술 배치, 계정 저장에는 영향을 주지 않는다.
