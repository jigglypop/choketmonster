# 기술 배치와 자동 공격

월드의 **기술 배치** 버튼이나 팀·박스 상세에서 기술을 편집한다. ▲▼로 공격·변화 구분 없이 순서를 자유롭게 바꾸며, 각 칸의 선택 목록에서 현재 종과 진화 전 종이 현재 레벨까지 배우는 기술을 골라 교체할 수 있다. 빈 칸에는 최대 네 칸까지 추가한다. 이미 장착한 기술은 다른 칸에 중복으로 넣을 수 없다. 전투·포획 선택 중에는 편집을 잠근다. 월드 버튼, 숫자 1~4, 일반 배틀 화면 모두 같은 표시 순서를 따른다.

`Monster.moveOrder`에는 기술 ID의 표시 순서를 저장한다. 순서만 바꿀 때는 실제 `moves` 배열과 신경 입력·출력 슬롯, PP, 개체별 회로 상태를 재배치하지 않는다. `getMoveLayout`이 표시 위치를 원래 슬롯에 연결한다. 레벨업과 진화에서는 남아 있는 기술의 순서를 유지하고 새 기술을 추가한다. IndexedDB·내보내기·서버 저장에서 같은 선택을 보존하며 TypeScript와 Rust가 중복과 불법 ID를 검사한다.

기술을 교체할 때는 원래 상태를 IndexedDB에 백업한다. `movePpReserve`는 미장착 기술의 남은 PP를 보관한다. 사용한 기술을 빼고 다시 장착해도 남은 PP로 돌아오며, 치료는 장착·미장착 기술 모두 회복한다. 서버도 예비 PP의 기술 ID, 습득 가능 레벨, 상한, 현재 기술과의 중복을 검사한다. 교체가 개체별 뇌 가중치나 기술 학습 기록을 지우지는 않지만 이전 행동에 대한 임시 보상 연결은 끊는다.

새 개체 생성과 자동 습득은 실제 엔진에서 피해를 줄 수 있는 공격을 최소 하나 보존한다. 사용자가 직접 편집할 때는 변화 기술만 선택할 수도 있다. 공격이 없는 기존 개체에는 **공격 기술 배치** 바로가기도 제공한다.

자동 배틀은 상대에게 면역되지 않고 PP가 남은 유효 공격 중에서 매 턴 선택한다. 공격이 없으면 사용 가능한 변화 기술을 선택하고, 모든 PP가 없으면 엔진의 발버둥을 사용한다. 빗나감·잠듦·마비 등 배틀 규칙 때문에 공격을 선택해도 피해가 없을 수 있다. 이 우선순위는 게임 제어 규칙이며 학습 향상이나 생물학적 지능을 뜻하지 않는다. 정책 비교와 리플레이 근거는 [실험 문서](experiments.md)에 기록했다.
