# 개체값과 특성 범위

## 원본

종별 특성 ID·슬롯·숨겨진 특성 여부·한국어/영어 이름은 `src/data/source-manifest.json`에 고정한 PokéAPI CSV 커밋에서 생성한다. `scripts/generate-pokemon-abilities.ts`가 원본 체크섬과 1~1025번 종의 기본 폼 특성표를 TypeScript와 Rust 검증 자료로 함께 만든다.

## 개체값

새 개체는 HP·공격·방어·특수공격·특수방어·스피드에 각각 0~31의 값을 가진다. 게임 시드와 개체 ID만 사용하는 별도 난수열로 생성하므로 전투·출현 난수열을 소비하지 않는다. 성장, 사탕, 중복 합치기와 진화는 남긴 개체의 값을 그대로 사용한다. 과거 저장은 여섯 값을 0으로 한 번 이관해 기존 계산 능력치를 정확히 보존한다.

## 실행되는 특성

- 심록, 맹화, 급류, 벌레의알림: HP가 최대치의 1/3 이하일 때 해당 타입 공격을 1.5배로 계산한다.
- 부유: 땅타입 공격을 무효화한다.
- 옹골참: 일격필살을 막고, HP가 가득 찬 상태에서는 한 번의 공격으로 쓰러지지 않게 HP 1을 남긴다. 연속 공격의 다음 타격은 막지 않는다.
- 저수, 축전: 해당 타입 공격을 무효화하고 최대 HP의 1/4을 회복한다.
- 타오르는불꽃, 피뢰침, 전기엔진, 초식, 마중물: 타입 무효만 적용하며 원작의 능력치 상승·공격 유도·후속 강화는 적용하지 않는 부분 지원이다.
- 건조피부: 물타입 무효와 회복만 적용하며 날씨와 불꽃 약점 효과는 적용하지 않는 부분 지원이다.

그 밖의 특성은 원본 이름과 슬롯을 개체 정보에 보존하지만 전투에는 적용하지 않는 `display-only` 상태다. UI는 이 상태를 효과 구현으로 표현하지 않는다.
