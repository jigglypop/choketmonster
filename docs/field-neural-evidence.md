# 들판 자율 행동의 신경 회로 근거

들판 시뮬레이션은 배포된 MaleCNS v1.0 커넥톰 부분 회로(`malecns-v1.0-dna02-neighborhood-128`)를 사용한다. 이 회로에는 실측 뉴런 128개와 실측 방향성 연결 3,623개가 있다. 들판의 각 개체는 영속적인 `Brain` 상태를 따로 소유한다. 들판 상태, 입력·출력 가중치, 학습 기록은 전투용 뇌와 분리되어 있으며, 모든 개체는 변경되지 않는 공통 그래프 데이터를 참조한다.

커넥톰은 재귀 연결 구조로 사용될 뿐, 완성된 초파리 뇌나 생물학적인 포켓몬 제어기가 아니다. 다음 요소는 게임을 위해 직접 설계했다.

- 입력 12개: 편향값, 가장 가까운 음식까지의 정규화된 x/y 거리, x/y 방향 부호, x/y 절대 거리, 위·오른쪽·아래·왼쪽 칸의 막힘 여부, 에너지
- 들판 틱마다 감각 우회 없이 재귀 계산 4회
- 출력 행동 5개: 위, 오른쪽, 아래, 왼쪽, 쉬기
- 보상: 틱마다 `-0.01`, 음식까지 거리가 한 칸 줄거나 늘 때 `+/-0.08`, 막힌 이동에 `-0.3`, 음식 획득에 `+2`
- 직접 설계한 출력 판독층에 적용하는 제한된 Q-learning

장애물, 충돌, 이동, 음식 생성, 보상 계산은 일반적인 게임 규칙이다.

## 재현 가능한 정책과 평가

다음 명령으로 재현한다.

```powershell
npx tsx scripts/evaluate-field.ts
npm test -- --run tests/field.test.ts
```

첫 번째 명령은 고정 시드 `4204204`, 탐험률 `0.12`로 하나의 정책을 20,000틱 동안 학습한 뒤 다음 파일을 쓴다.

- `public/data/field-policy.json`
- `artifacts/field-neural-evidence.json`

평가 중에는 학습을 끄고, 학습에 사용하지 않은 시드 6개에서 각각 1,200틱을 실행한다. `고정 미학습`은 학습하지 않은 결정론적 판독층이다. `연결 차단`은 학습된 입력·판독층과 상태 형태를 유지하면서 모든 재귀 연결 가중치를 0으로 바꾼다. `무작위`는 다섯 행동을 균등하게 선택하는 비교 기준이다.

| 조건 | 평균 음식 | 평균 충돌 | 평균 보상 |
| --- | ---: | ---: | ---: |
| 무작위 | 10.50 | 104.67 | -28.80 |
| 고정 미학습 | 0.00 | 599.50 | -193.17 |
| 학습 및 실측 연결 | 7.00 | 383.67 | -110.93 |
| 학습 및 연결 차단 | 1.67 | 862.50 | -266.92 |

학습 정책은 시드당 평균 음식 획득에서 고정 미학습 정책보다 7.00개, 연결 차단군보다 5.33개 많았다. 그러나 무작위 기준보다 3.50개 적었고 충돌도 더 많았다. 이 제한된 결과는 실측 재귀 연결이 이 제어기의 행동과 점수에 영향을 준다는 것을 보여준다. 생물학적 학습이나 지능, 생물학적으로 대응된 감각운동 회로를 입증하지는 않는다.

평가에서는 평가 전후 판독 가중치와 갱신 횟수가 변하지 않는지, 저장 체크포인트가 정확히 재생되는지, 빠졌다가 다시 들어온 개체가 격리된 뇌 기억을 유지하는지, 들판 스냅샷이 그래프 연결을 중복 저장하지 않는지도 확인한다. 렌더링과 UI 스케줄링은 시뮬레이션 외부에 있으며 시뮬레이션 난수를 소비하지 않는다.

## 실행 계약

`FieldSimulation`은 그래프, uint32 시드, 최대 6개의 `{id, speciesId}` 구성원, 선택적인 체크포인트와 정책을 받는다. `step(learning)`은 자율 이동을 한 틱 진행한다. `setMembers`는 구성원 ID별 기억을 보존하고 진화 후 종 번호를 갱신한다. `setRecurrentEnabled(false)`는 학습 가중치를 초기화하지 않고 같은 뇌에 연결 가중치가 0인 그래프를 제공한다. `snapshot()`은 개체의 뇌 상태에 `graphId`만 기록하며, 복원할 때 호출자가 공통 그래프를 다시 제공한다.

실행 중인 개체는 위치, 방향, 에너지, 최근 12개 입력, 선택 행동, 최근 보상, 목표 음식, 음식 획득 수, 충돌 수, 활동 시각화용 읽기 전용 `BrainState`를 공개한다. 음식 항목의 형식은 `{id, x, y}`이다. 체크포인트를 복원할 때는 좌표와 고유성, 수치 범위, 행동 범위, 감각 우회 비활성화, 그래프 일치 여부, 배치 충돌 여부를 검증한다.
