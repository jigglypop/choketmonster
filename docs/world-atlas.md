# 월드 아틀라스와 현재 지원 범위

## 현재 제품 정책

새 게임과 지역 지도에서는 **관동과 성도**를 탐험할 수 있다. 두 지역 모두 공개된 도시·도로 정보를 게임용 좌표로 압축하고 자체 지형·건물을 생성한 3D 재구성이다. 외부에서 완성된 지역 GLB 파일을 받아야 한다는 조건은 사용자의 지도 재구성 요청에 맞춰 폐기했다. 원작의 타일·미술 자산을 복제하지 않는다. 출처와 확보한 모델의 범위는 [지역 맵 원본 조사](world-map-sources.md)에 기록했다.

관동은 기존 레드 기준 장소별 배치를 유지한다. 성도 `johto-v2`는 연두마을부터 검은먹시티까지 10개 도시, 29~46번 도로와 연결 27번 도로, 숲·동굴·수로를 연결했다. 동쪽 끝 동성폭포에서는 배지 8개가 필요한 은빛산 탐험 구역으로 이어진다. 동굴은 같은 지형 위의 탐험 구역이며 원작의 다층 실내를 복원하지 않았다.

마을 포장 타일 아래 지형은 포장 반경과 렌더 삼각형 한 칸의 여유 폭까지 같은 높이로 맞추고, 바깥 완충 구간에서 원래 지형으로 부드럽게 연결한다. 이 높이 보정은 통행 가능 여부, 건물 충돌, 기존 위치 좌표와 장소별 야생 출현표를 바꾸지 않는다.

성도 조우 자료는 고정 PokéAPI 커밋의 골드 버전에서 가져온 낮 시간 walk/surf 자료다. 원본 풀에 등장하는 종을 기존 리깅 유무로 제외하지 않으며, 리깅이 부족한 모델은 직접 리깅하는 작업 대상으로 관리한다. 모델이 없는 종을 다른 종으로 대체하지 않는다. 현재 런타임은 장소별 원본 슬롯 가중치로 종을 선택하고, 레벨은 게임용 지역 진행 구간에서 선택한다. 원작의 종·레벨 결합 확률이나 시간·무리 출현을 재현하지 않는다. 원본에 skin만 있고 애니메이션 클립이 없는 `rigged-static`은 골격 애니메이션 확보 완료를 의미하지 않는다.

새 모험은 성도 스타터로 시작해 성도 체육관·리그를 마친 뒤 관동으로 이어진다. 두 지역 배지와 사천왕·챔피언 진행을 따로 저장하고, 양 리그를 마치면 은빛산 레드전이 열린다. 기존 관동 저장의 여행과 초반 레벨은 보존한다. 성장·진행 수치는 [캠페인 레벨 설계](campaign-balance.md)에 정의했다.

통합 도감의 251종은 두 지역의 도감 목록이며 전 종의 입수 경로가 구현됐다는 뜻은 아니다. 실제 출현 장소가 없는 종은 화면에 표시한다. 버전 선택은 수집 기록에만 적용하며 지역 이동이나 살아 있는 야생 개체 재추첨을 일으키지 않는다. 다른 지역 버전과 1,025종 원본 메타데이터, 기존 보유 개체 기록은 보존한다.

`atlas.ts`의 미지원 8개 지역 정의는 과거 저장 해독용으로만 유지하며 선택지에는 넣지 않는다. 기존 `johto-atlas-v1` 저장은 원본을 IndexedDB에 백업하고 성도 v2의 안전한 위치로 옮긴다. 다른 미지원 지역 저장은 관동으로 이전한다. 보유 개체·개체별 뇌·학습·수집·진행 중인 전투는 보존하고, 배틀 밖 야생 개체와 재생성 대기는 현재 지역의 지원 풀에 맞춘다. 지역 정보가 없는 이전 저장은 관동으로 해석한다.

## 과거 압축 atlas 정의

기존 성도 v1과 나머지 미지원 여덟 atlas는 과거 프로토타입에서 대표 지명과 지역 특징을 약 `-120..120` 좌표에 재배치한 코드 생성 지형이다. 원작 게임의 맵 데이터나 타일을 복제한 것이 아니며, 거리·방향·축척·높이·건물 배치·연결 순서는 작은 월드 탐색을 위해 설계한 값이다. 각 정의에는 고유 위치 ID, 연결로, 안전 도착점, 연속 높이 함수, 건물 충돌과 게임용 서식 종 목록이 있다. 체육관과 관문 진행은 구현하지 않았다.

53개 버전에서 지역 ID를 판정하는 매핑도 저장 호환과 도감 분류를 위해 유지한다. 이 매핑은 현재 해당 지역을 여행할 수 있다는 뜻이 아니다. `colosseum`과 `xd`의 호연 분류, `champions`의 관동 분류, `legends-za`와 `mega-dimension`의 칼로스 분류, `legends-arceus`의 히스이 분류도 같은 용도다.

장소 및 지역 표기의 기준은 Pokémon 공식 자료다. Pokémon Company의 [Pokémon Evolutions 공식 보도 자료](https://press.pokemon.com/en/Pokemon-Evolutions/Focus/Pokemon-Evolutions-videos)는 관동부터 가라르까지 지역 계보를 확인하는 데 사용했다. [Pokémon Legends: Arceus 공식 스토리](https://legends.arceus.pokemon.com/en-us/story/)는 히스이와 축복마을, [Pokémon 공식 부모 안내](https://parents.pokemon.com/en-us/video-games-and-apps/)는 팔데아, [가라르 공식 관광 안내서](https://assets.pokemon.com/assets/cms2/pdf/video-game/sword-shield/Galar_Tour_Brochure_US.pdf)는 가라르 표기를 확인하는 데 사용했다.

## 이동과 자동 복귀

월드 이동 속도는 기존 능력치 계산 결과의 2.2배이고 상한은 초당 11월드 단위다. 전투, 몬스터볼 보충과 신경 계산 시간은 가속하지 않는다. 탐험 중 이동 입력 없이 3초가 지나면 자동 이동 모드로 돌아간다. 키·터치 입력 또는 지정 목적지 이동 중에는 수동 상태를 유지하고, 일시정지·지도·전투·포획 선택 중에는 자동으로 전환하지 않는다.

## 화면과 거리 기준 LOD

### 야생 출현과 지역 이동

레드 등 관동 버전에서 먼 야생 개체를 2~3초마다 교체하던 시간 기반 밀도 보정을 제거했다. 가만히 있는 동안 거리 때문에 개체를 재추첨하지 않는다. 마지막 불러오기 지점에서 24월드 단위 이상 이동했을 때 38단위 밖 개체만 새 주변 구역의 개체로 교체하며, 선택한 개체와 배틀 대상은 보존한다. 포획·전투로 사라진 개체의 기존 4~6초 재등장은 유지한다. 마지막 지역 불러오기 위치를 저장해 새로고침으로 추가 교체가 일어나지 않게 한다. 기존 저장의 밀도 타이머는 가져오기 호환용으로만 읽는다.

수집 버전과 관계없이 야생 종 배치는 관동 레드, 성도 골드의 위치별 목록으로 고정한다. 레벨은 캠페인에 정의한 지역별 구간을 사용한다. 버전 변경으로 살아 있는 개체, 선택 대상이나 재등장 대기를 재추첨하지 않는다. 예전 통합 도감 등에서 확장된 야생 목록을 저장한 경우 IndexedDB에 원본을 백업하고 현재 지역의 고정 목록으로 한 번만 정리한다. 진행 중인 배틀·포획과 보유 개체·수집 기록은 유지한다. 이후 새로고침은 이동 중 다른 구역으로 걸어간 개체를 다시 배치하지 않는다.

관동 위치별 목록은 기존 게임 설정이며 성도는 골드 원본을 장소별로 요약한다. 원작의 풀숲 걸음별 출현 확률을 복원한 것은 아니다.

체육관을 이기면 획득 배지, 실제 상금과 열린 관문을 앱 모달로 표시한다. 보상 저장 뒤 이벤트를 띄우며 모달을 닫기 전에는 월드 시간이 흐르지 않는다. 모달 확인은 보상을 다시 지급하지 않는다.

팀·박스의 개체 관리에는 같은 종을 선택한 한 마리로 합치는 버튼이 있다. 확인 모달에 마릿수, 받을 경험치와 레벨 100 상한 초과분을 표시하며, 실행 전에 IndexedDB에 전체 저장 백업을 남긴다. 대상과 모든 재료를 검증한 뒤 한 번에 처리하고, 남긴 개체의 회로 기억·학습 기록과 도감 포획 기록을 유지한다. 박스 개체가 유일한 생존 개체가 되면 팀으로 이동한다.

### 렌더링

작은 동행 포켓몬의 표시 높이는 최소 1.65로 올리고, 큰 종의 상한 4.8은 유지했다. 기본 카메라 거리와 최대 줌아웃을 줄여 캐릭터가 지형에 묻히는 비율을 조정했다. 저장 좌표나 이동·충돌 단위는 바꾸지 않는다. 가까운 통행 불가 지형 가장자리는 노란 경계선으로 표시하고 지도 범례에서도 설명한다. 모바일에서는 탐험 조작 패널을 처음에 접어 캐릭터와 지형을 볼 공간을 확보한다.

성도 v1을 불러올 때는 이전 장소 ID에 해당하는 새 장소로 좌표를 옮긴 뒤 통행 가능한 지점에 배치한다. 연두마을의 옛 좌표를 새 지도의 진청시티로 잘못 해석해 방문 기록이 추가되는 문제를 실제 브라우저 이전 검사에서 발견해 수정했다. 원본 백업과 파트너의 회로 상태, 골드 수집 기록을 유지하며 새로고침·모바일 복원을 확인했다.


- 지형은 40×40 단위 구역으로 나누며 플레이어 주변과 카메라에 보이는 구역만 만든다. 가까운 지형 청크는 12분할 상세 메시, 먼 청크는 4분할 메시를 사용하고 해상도 경계에는 연결 면을 둔다.
- 포켓몬은 카메라 시야와 거리를 통과한 개체 중 데스크톱 최대 8개, 모바일 최대 4개만 실제 3D 모델로 표시한다. 3D 반경은 각각 32·22 월드 단위다.
- 3D 반경 밖의 중거리 개체는 이미지로 대체하지 않고 컬링한다. 모델을 불러오는 중이거나 오류가 발생하면 개체 자리의 대체 스프라이트 대신 UI 상태를 표시한다.
- GLB 요청은 동시에 최대 3개이며 Draco 디코딩 작업자는 최대 2개다. 아직 시작하지 않은 요청이 시야에서 빠지면 취소하고, 시작한 전송은 완료 뒤 캐시 정책으로 관리한다.
- 참조가 없는 모델부터 LRU로 정리하며 캐시 목표는 16개다. 자연 소품도 가까운 시야에 실제 배치가 있을 때만 원본 모델을 요청한다.
- 원본 모델에 애니메이션 클립이 없으면 이동에 맞춘 기울기와 상하 움직임을 게임 코드에서 적용한다. 이는 원본 골격 애니메이션이 아니다.

기존 151종에 추가한 820종 모델 전체 약 306 MB를 검사해 971종을 실행 경로에 연결했다. 별도 Pokémon HOME 계열 원본에서 나머지 54종의 기하 파일 약 30 MB도 로컬 연구용으로 확보했지만 텍스처가 없고 라이선스를 확인하지 못했으므로 실행 및 배포 자산으로 사용하지 않는다.

## 역사적 검증 기록

아래 내용은 비관동 압축 atlas가 UI에 노출되던 이전 구현의 당시 검증 기록이다. 현재 제품의 새 지역 여행 성공 결과나 이번 문서 변경 뒤 새로 실행한 테스트 결과가 아니다.

- 당시 `tests/world-atlas.test.ts`는 관동 위임 동일성, 10개 지역 ID, 53개 버전 매핑, 프로토타입 연결 그래프의 보행 가능성, 높이 연속성, 건물 충돌, 안전 도착, 서식 종 범위와 저장된 지역 ID 복원을 검사했다.
- 당시 `tests/world-lod.test.ts`, `tests/world-regions.test.ts`, `tests/ui/world-regions.spec.ts`는 거리 LOD, 프로토타입 지역 전환, 저장 복원과 모바일 예산을 검사했다.
- 2026-09-13 기록에는 Vitest 27개 파일·140개 검사, Rust 11개 검사, 브라우저 4개 시나리오와 프로덕션 빌드 통과가 적혀 있었다. 성도 프로토타입 화면과 지형 생성 관측도 이 과거 결과에 포함된다. 이를 현재 성도 맵 확보 또는 10개 지역 플레이 지원의 증거로 해석하지 않는다.

## 이전 관동 한정 정책 검증 (2026-09-13)

지역·저장·모델·LOD 단위 검사와 프로덕션 빌드를 확인했다. 브라우저에서는 기존 성도 저장을 가져와 관동 전국도감으로 이전한 뒤, 실제 치코리타 GLB의 Draco 디코딩, 원본 백업의 성도·골드 값과 개체 기억, 현재 저장의 지역·수집 기록, 새로고침 복원을 검사했다. 나오하 GLB 표시, 미지원 버전 수집 버튼 비활성화, 경험치 합치기·놓아주기, 모바일 화면과 계정 오류 복구도 확인했다. 수동 이동 입력을 멈춘 뒤 자동 모드로 돌아오는 기존 동작도 재검사했다.

검증 중 저장 해독기가 검사용 월드 생성 과정에서 원본 버전 값을 바꾸는 문제를 발견했다. 검사용 게임 복사본을 사용하도록 수정해, 이전 전에 IndexedDB에 원본 지역과 버전·기억이 함께 남는 것을 확인했다. 브라우저 모델 검사에는 다운로드·해시를 검증한 동일 GLB 파일을 사용했다. 외부 원본 서버의 응답 속도와 실제 휴대폰 GPU 성능까지 이 검사로 보증하지 않는다.
