# 전체 진화 경로와 상점 도구

모험 상점에서 진화 도구를 구매한다. **팀·박스 → 대상 개체 → 진화**에서 진화형을 선택하면 도구 1개를 소비하며, 재고가 없으면 필요한 도구를 자동 구매한다. 금속코트는 개당 ₩4,000이며 롱스톤→강철톤, 스라크→핫삼에 각각 1개가 필요하다. 탐험 패널에는 프렌들리숍을 표시하지 않는다.

## 게임 규칙과 저장

- 전국도감 1,025종에 연결된 **483개 진화 경로, 553개 원본 조건행**을 구조화한다. 기본·비기본 버전의 여러 방법과 폼 제약을 모두 보존하고 진화 화면의 접힌 원본 조건에서 확인한다.
- 친밀도 자연 진화는 사용자 요청으로 비활성화했다. 해당 경로는 특수진화 캡슐로 진행하며 과거 친밀도·간식 보유량은 삭제하지 않는다. 나머지 자연 진화는 레벨, 아름다움·애정, 성별, 장착 기술·타입, 공격/방어 비교, 팀의 종·타입, 시간·장소·지방, 걷기, 기술 사용과 반동 피해 조건을 판정한다. 원본 데이터의 0은 누락하지 않으므로 카포에라는 공격=방어를 확인한다.
- 성별과 초기 친밀도는 원본 종 특성과 개체 ID로 결정한다. 기존 저장도 같은 ID에서 동일하게 복원하며 게임 난수를 소비하지 않는다. 레벨업마다 친밀도 +5, 파트너의 실제 이동 128걸음마다 +1이다. 이 증가량과 1월드 단위=1걸음은 자체 게임 규칙이다.
- 시간 조건은 기존 출현 시계를 사용한다. 지상 낮 밝기와 시계 숨김은 유지한다. 실제 연결된 다른 플레이어가 있으면 멀티플레이 조건을 충족한다. 비가 없는 현재 월드에서는 비 조건을 임의로 참으로 만들지 않는다.
- 껍질몬은 토중몬이 Lv.20 이상이며 팀에 빈 자리와 몬스터볼이 있을 때 아이스크와 함께 별도 개체로 생성한다. 아이스크는 원래 개체 ID·기억을 유지하고 껍질몬은 새 ID를 받는다.
- 전용 도구를 선택하면 도구 1개로 해당 진화를 진행한다. 교환·시간·성별 등의 추가 조건을 대체하지만, 지역 모습은 실제 개체와 지원하는 진화형이 일치해야 한다. 기본 야돈에 가라두구팔찌를 사용하거나 기본 포푸니를 포푸니크로 진화시킬 수 없다.
- 원본에만 있는 회전·기기 뒤집기·속공/강공·급소 도전·특수 탑·특수 바위·보름달·대장의징표·코인 수집 등은 원작 이벤트를 재현했다고 주장하지 않는다. **특수진화 캡슐**을 선택해 해당 조건을 대체한다. 친밀도·성별·기술 등의 조건도 같은 대체 경로를 선택할 수 있다. 단순 레벨 진화는 캡슐로 건너뛰지 않는다.
- 대체 경로는 목표 종을 얻는 자체 규칙이며 추가 모습 모델을 구현했다는 의미가 아니다. 실제 플레이 지도·리깅 검증 범위는 1~649번이고, 이후 종의 기존 저장과 진화 데이터도 처리한다.
- 전투 중, 재고 부족, 맞지 않는 도구나 진화형은 거부한다. 분기 진화에서는 선택한 도구만 소비한다.
- 개체 ID, 레벨·경험치 진행률과 개별 회로 기억을 유지한다. 과사삭벌레 계열처럼 진화 후 경험치 성장식이 다른 경우 누적 경험치를 새 성장식의 같은 레벨·진행률로 환산해 저장 오류를 막는다.
- 과거 12종 가방은 새 품목을 0개로 채워 복원한다. 서버도 과거 가방과 새 60종 가방을 지원한다. 성장 기록은 개체별로 저장하며 기존 기록 생략을 허용한다. 명시적인 잘못된 수량·성장치·알 수 없는 품목은 거부한다.
