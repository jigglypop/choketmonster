# 실제 커넥톰 × 관동 151종: 구현 완료 조건

사용자 요청은 실제 포켓몬 151종을 잡고 육성·진화하며 플레이할 수 있는 초켓몬스터다. 기존 합성 회로 3종의 관찰 화면을 완성으로 간주하지 않는다. API 비용 없이 로컬에서 실행하는 한글 게임으로 구현한다.

## 게임

- 001 이상해씨부터 151 뮤까지 실제 이름, 타입, 능력치, 이미지, 기술·진화 데이터와 출처.
- 새 게임과 스타터 선택, 이동 가능한 탐험 지역, 야생 조우와 포켓몬별 출현 경로.
- 기술과 PP, 타입 상성, HP, 기절·교체·도주가 있는 턴제 전투.
- 볼 수량, HP·포획률을 반영한 포획, 파티 6마리와 보관함, 발견·포획 도감 기록.
- 승리 경험치와 레벨 성장, 레벨·돌·교환 계열의 실제 진화 경로. 혼자 실행할 수 있는 게임 내 교환소 제공.
- 치료소, 가방, 회복·진화 아이템, 상점과 반복 가능한 자원 획득. 전멸 후 재개 가능.
- 지역/트레이너 진행과 전설 조우를 포함해 151종 모두 게임 플레이로 획득 가능한 경로.
- 자동 저장, JSON 내보내기·불러오기, 새로고침 이후 진행·개체별 기억 복원.
- 데스크톱과 모바일 조작, 실제 브라우저에서 탐험→전투→포획→육성→진화→저장 흐름 확인.

## 신경 회로

- 공개된 실제 초파리 원본을 내려받아 검증 가능한 회로를 만든다. URL·버전·라이선스·SHA-256·선택 기준을 보관한다.
- 그 회로의 활동값이 자율 행동/선택에 실제 영향을 준다. 개체마다 신경 상태와 학습 기억을 분리한다.
- 회로 범위와 직접 설계한 입력·출력·학습을 화면과 문서에서 확인할 수 있다.
- 연결을 제거하거나 감각 직접 경로만 남기는 비교로 실제 계산 경로의 기여를 확인한다. 과학적 학습 성공은 별도 주장으로 취급한다.
- 정책 비교·평가 중 가중치 고정·리플레이와 실제 데이터 실행 증거를 남긴다.

## 완료 증거

관련 단위 테스트, 151종 데이터·진화·획득 경로의 범위 검사, 브라우저 주요 흐름, 프로덕션 빌드, 실제 데이터 실험과 리플레이를 확인한다. 기능 목록과 검증 범위를 대응시킨 최종 결과 문서를 남긴다. 미구현·미검증 항목이 남으면 목표를 완료로 표시하지 않는다.
