# 가능성 점검 · 2026-09-10

**가능하다.** 다만 현실적인 첫 제품은 “초파리 회로에서 영감을 받은, 개체별 기억을 가진 몬스터 게임”이다. 실제 커넥톰 전체를 연결하는 연구 버전은 별도로 검증해야 한다. 처음부터 수백 마리를 모두 전체 뇌로 실시간 계산하는 설계는 피하고, 우선 한 마리의 행동 고리를 검증하는 편이 타당하다.

## 공유한 사례에서 확인한 것

Threads 공유 링크는 직접 본문을 열지 못했다. 따라서 링크 속 게시물과 동일하다고 단정하지 않았다. 관련 원본 프로젝트 [DOOMFLY](https://github.com/nftechie/doomfly)의 2026-09-10 README는 게임 화면을 감각 뉴런에 입력하고 신경 활동을 조작 버튼으로 바꾸는 실험을 설명한다. 동시에 **학습된 생존 능력은 입증되지 않았고 현재 후보가 검증 관문을 통과하지 못했다**고 명시한다. “둠을 조작한다”와 “둠을 잘하도록 배웠다”를 구분해야 한다.

초파리 커넥톰에 기반한 계산 모형이 감각-운동 회로의 반응을 예측하고 일부 실험으로 검증한 연구는 있다. 그것이 임의의 게임 학습이나 동물의 의식 재현을 보장하지는 않는다. [Shiu et al., Nature (2024)](https://www.nature.com/articles/s41586-024-07763-9).

FlyWire의 성체 암컷 뇌는 약 14만 뉴런 규모이며, 데이터셋과 필터에 따라 연결 수의 정의가 달라진다. 뉴런 수, 뉴런 쌍 사이의 가중 연결 수, 개별 시냅스 수를 섞어 성능이나 규모를 비교하면 안 된다. [Schlegel et al., Nature (2024)](https://www.nature.com/articles/s41586-024-07686-5), [공식 데이터 포털](https://codex.flywire.ai/api/download).

## 초켓몬스터의 제품 구조

한 몬스터는 `외형 + 회로 정의 + 동적 뇌 상태 + 학습된 기억 + 기록`이다. 실제 커넥톰을 사용할 때는 같은 해부학적 연결 구조를 공유해도 상태와 가소성 가중치는 개체마다 분리한다. 몬스터의 게임 속성은 몸과 감각·출력 인터페이스에서 정의할 수 있다. 행동을 보기 좋게 만들려고 숨겨진 길찾기 AI로 교체하면 그 정책 종류를 별도로 표시해야 한다.

첫 루프는 **감각 → 뇌 → 행동 → 환경 변화 → 보상 → 기억**이다. 먹이 찾기는 짧은 시간에 반복할 수 있고, 보상·장애물·상태를 기록하기 쉬워 첫 검증 과제로 선택했다. 이후 위협 회피, 목표 변경, 간단한 전투로 확장할 수 있다. 이 우선순위는 제품/실험 설계상의 판단이다.

## 처음 검증한 범위와 현재 구현

- 초기에는 3종 창작 개체와 32노드 합성 채집 과제로 학습·평가·재현 구조를 만들었다. 그 코어와 결과는 비교 자료로 보존한다.
- 현재 제품은 실제 관동 151종을 사용하며, 포획·기술 전투·경험치·레벨/돌/교환 계열 진화와 저장을 게임 규칙으로 구현한다.
- 실제 MaleCNS v1.0에서 DNa02 쌍을 중심으로 선택한 128개 뉴런과 실측 연결 3,623개를 배틀 행동 계산에 사용한다. 원본 3개 파일의 체크섬과 선택 기준을 보존했다. [데이터 근거](connectome-source.md).
- 별도 학습/평가 시드, 무작위/규칙/학습 전/학습 후 비교, 평가 중 학습 차단, 완전한 정책 체크포인트, 프레임 해시 재현.
- 원본 회로와 연결 가중치를 0으로 만든 회로의 비교에서 행동 차이를 확인했다. 이는 회로 계산의 기여이며 전략의 우수성이나 생물학적 학습 검증은 아니다. [실행 근거](game-neural-evidence.md).
- 간결한 AGENTS.md, 목적이 좁은 실험 스킬, 다음 단계의 완료 조건.

## 아직 검증하거나 구현하지 않은 것

전체 뇌 계산 성능, 세포형에 근거한 감각/운동 매핑, 생물학적 가소성 규칙, 게임 전략의 일반화는 검증하지 않았다. 포켓몬 본가의 전체 스토리·모든 기술의 세부 효과·온라인 멀티플레이는 이번 로컬 게임의 범위 밖이다. 실제 포획·진화·성장과 체육관 진행은 게임에서 구현하고 기능별 실행 결과로 확인한다.

전체 뇌는 별도 계산 프로세스로 분리하고 화면에는 결과를 전달하는 설계가 후보이다. 다수 개체에서 구조는 공유하고 현재 행동하는 개체만 계산하는 방식을 먼저 측정할 수 있다. 메모리·턴 지연·학습 효과를 실측하기 전에는 전체 뇌 실시간 대규모 게임을 약속하지 않는다. 관련 원본 역시 전체 그래프 계산을 브라우저 밖에서 실행하도록 안내한다. [DOOMFLY 실행 안내](https://github.com/nftechie/doomfly#run-the-neural-experiment).
