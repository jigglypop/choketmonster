# UI 정리와 최적화 — 2026-09-16

## 적용한 변경

- 공통 색상·글꼴·간격 기준을 `src/ui/design-system.css`에 모았다. 밝은 페이지는 흰색·연한 녹색, 모험 HUD는 짙은 녹색을 사용하며 포켓몬 타입 색은 유지한다.
- Pretendard 1.3.9에서 런타임 글자를 추린 Choket Sans를 자체 제공한다. 원본 2,057,688바이트에서 197,216바이트로 90.42% 줄었으며 브라우저에서 한 번 요청하고 실제 적용되는 것을 확인했다. OFL 원문·출처·해시는 `public/fonts/README.md`에 있다. 서브셋에 없는 사용자 입력은 시스템 한글 폰트로 표시한다.
- 포켓몬 이름·HP는 Drei `Html`로 표시하는 DOM이다. GPU 글꼴 아틀라스를 만드는 경로가 아니다. 기본 이름표 표시는 유지하되 데스크톱 최대 6개, 모바일 최대 3개를 선택·파트너·전투·다른 플레이어·거리 순으로 우선 표시한다. 이름표도 공통 글꼴을 사용한다.
- 동일한 월드 스냅샷이 반복되면 React 구독 알림을 생략한다. 이동·체력·이름·동작·안내 변화는 계속 반영한다. 이동 중 프레임이나 시뮬레이션 속도를 낮추지 않는다.
- 이동하는 지형 위의 HUD 배경 블러를 제거했다. 이름표에는 CSS containment를 적용했다.
- 헤더와 미니맵, 안내, 파트너, 채팅 높이를 ResizeObserver로 측정하여 글자 확대·줄바꿈에 따라 HUD 위치를 조정한다. 좁은 화면은 메뉴와 하단 패널을 접거나 스크롤해서 모든 조작에 접근한다.
- 팀·박스, 도감, 상점, 계정, 교환의 카드·필터·버튼 스타일을 통일했다. 모바일 빈 팀 슬롯은 한 행으로 묶고 상점 가격·구매 버튼과 필터가 서로 밀리지 않도록 수정했다.

## 발견하고 수정한 배치 문제

- 글자 150%에서 헤더 설정 버튼이 화면 밖으로 밀림.
- 안내와 탐험 메뉴, 미니맵과 이름표 버튼의 겹침.
- 작은 세로 화면에서 펼친 파트너 패널이 탐험 메뉴를 덮음.
- 가로 화면에서 탐험 메뉴가 하단 내비게이션을 침범하고 기존 CSS가 상점·박스 진입을 숨김.
- 전투 패널의 왼쪽 배치에서 미니맵·채팅과 겹침.
- 작은 화면의 팀 카드, 필터, 상점 가격·버튼 줄바꿈과 팝업 닫기·스크롤 영역.

## 측정 범위

레이아웃 검사는 모델 요청을 차단하고 월드 프레임을 정지하여 HTML 배치를 검사했다. 별도 렌더 검사에서는 실제 GLB 8개를 불러오고 이름표를 켜고 껐으며, 같은 장면에서 GPU 텍스처 수가 증가하지 않았다. 변경 후 이름표는 6개 이하로 표시됐다.

렌더 검사는 Windows Headless Chrome의 WebGL2 fallback 환경이었다. 프레임 시간 변동이 커서 실사용 FPS 개선률로 해석하지 않는다. 이번에 확인한 절감은 폰트 바이트, 이름표 DOM 수와 동일 스냅샷 갱신이다. WebGPU 실기기, 로그인한 교환방, 임의의 긴 사용자 입력 전체 조합까지 검증한 것은 아니다. 빌드의 약 9MB JavaScript 번들은 여전히 별도 분할 최적화 대상이다.
