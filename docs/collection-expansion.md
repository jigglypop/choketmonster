## 자료와 게임 규칙의 범위

버전 목록은 원본 지역도감 수록표이며 본가의 야생 출현표가 아니다. 현재 비관동 버전을 선택하면 해당 도감의 종과 자료를 열람하며 다른 지역으로 이동하지 않는다. 버전마다 그 버전에서 잡거나 진화한 기존 기록은 유지한다. 전국도감은 3D 지원이 연결된 971종 범위에서 추가 세대 종까지 관동 월드에 배치해 수집하는 선택지다. 원본 도감이 없는 버전은 목록에서 비활성화한다.

원본 서식지가 `unknown`인 종은 타입으로 플레이 지형을 지정한다. 물 타입은 물가, 풀·벌레는 숲, 바위·땅·강철·얼음은 산악, 나머지는 초원이다. 원본 서식지 값을 변경하지 않는다. 관동 기본 모험은 기존 출현 목록과 진화·배지 관문을 유지한다.

플레이 대상은 각 종의 기본 폼이다. 추가 폼은 도감 상세에서 이미지와 메타데이터를 열람한다. 기존 151종과 추가 820종의 모델 전체 약 306 MB를 검증해 971종의 3D 모델을 실행에 연결했다. 나머지 54종도 Pokémon HOME 계열 원본에서 약 30 MB의 기하 파일을 로컬 연구용으로 확보했지만 텍스처가 없고 라이선스를 확인하지 못해 실행 및 배포에 사용하지 않는다. 가까운 포켓몬만 3D로 표시하며 중거리 개체는 이미지로 바꾸지 않고 컬링한다. [월드 호환 구조와 LOD](world-atlas.md)를 참고한다. 복합 진화 89건은 원본 조건을 보존하되 게임에서 임의로 레벨 1 진화로 바꾸지 않는다. 미지원 특수 진화나 진화 도구에 해당하는 종도 전국도감의 관동 출현 규칙으로 수집할 수 있다.

자료 URL·고정 커밋·체크섬·라이선스는 [자료 출처](pokemon-sources.md), [모델 출처](pokemon-models.md), 두 원본 manifest와 모델 manifest에 기록했다. 모델 151개는 총 463,269,256바이트, 869개 애니메이션이며 GLB 구조·내장 리소스·원본 Git blob 해시·SHA-256을 검사했다. 배포 파일에서는 포켓몬 PNG·GLB 로컬 캐시를 제외하고 기존 고정 원본 URL을 참조한다.

## 저장과 보안의 경계

IndexedDB의 게임 본문과 로컬 revision을 한 트랜잭션으로 읽고 outbox를 만든다. 로그인 서버 응답이 기다리는 동안 새 로컬 저장이 생기면 이를 다시 읽는다. 늦은 응답은 최신 게임 본문을 덮어쓰지 않으며 계정 전환 후 이전 요청을 재전송하지 않는다. 다른 탭에서 세션 쿠키가 바뀌어도 `x-choketmon-profile`이 일치하지 않으면 서버가 403을 반환한다.

로그인 성공 후 서버 동기화가 실패해도 해당 계정의 로컬 모험과 outbox를 유지한다. 계정은 바뀌었지만 IndexedDB를 읽지 못한 경우에는 이전 모험을 재개하거나 빈 저장으로 취급하지 않고 재시도 화면을 표시한다. 로그아웃은 저장 체크포인트 응답을 받은 뒤 세션을 폐기한다.

전체 서버 회로의 큰 체크포인트와 재현 이력은 별도 기기 IndexedDB에 남는다. PostgreSQL에는 게임 상태·브라우저 부분 회로·기술 통계가 포함된다. 다른 기기의 로그인으로 전체 서버 회로 기억까지 옮기지는 않는다. 같은 seed를 다른 계정에 가져온 경우의 로컬 신경 기억은 계정 UUID를 포함한 scope로 분리한다.

서버는 저장 값의 일관성을 검증한다. 전투·포획·보상 이벤트를 서버가 직접 재실행하는 구조는 아니므로 정상 범위 안의 돈·수량·진행 위조까지 완전히 차단하지는 않는다. 세부 검증과 운영 제한은 [서버 문서](rust-server.md)에 있다.
