# 특수 기술 판정 보완 · 2026-09-17

## 이번 구현

- 일반 전투와 랭크전: 흑안개는 출전한 양쪽의 능력치 단계만 초기화한다. 클리어스모그는 피해가 들어간 상대만 초기화하며 강철 타입 면역에는 적용하지 않는다.
- 잠자기는 HP를 완전히 회복하고 기존 상태이상을 수면으로 바꾼다. 이후 두 번 행동하지 못하고 세 번째 행동에 깨어난다. 최대 HP 또는 불면·의기양양·절대안깸 특성에는 실패한다. 저장 복원 시 수면 시간은 유지한다.
- 치료방울·아로마테라피는 살아 있는 팀원의 일반 상태이상을 치료한다. 혼란·속박·씨뿌리기를 치료하는 것으로 확장하지 않는다. 치료방울의 다른 팀원 대상 방음·황금몸 예외를 반영했다.
- 고속스핀은 명중하여 피해를 준 경우 사용자 자신의 스피드를 올리고, 사용자의 속박·씨뿌리기를 제거한다. 기존 데이터의 범주만 따라 상대 스피드를 올리던 오류를 수정했다.
- 랭크전: 지구던지기·나이트헤드·분노의앞니가 위력 0으로 무시되던 문제, 교체 후 능력치 단계가 남는 문제, 면역 공격의 부가 능력치 변화, 과잉 피해를 이용한 흡수·반동 계산을 수정했다.
- 관련 특성은 일부 구현으로 표시한다. 모든 기술·특성을 원작과 동일하게 구현했다는 뜻은 아니다. 새 저장 필드를 추가하거나 기존 개체 데이터를 삭제하지 않는다.

## 근거와 검증

기술 이름·ID·일반 메타데이터는 저장소의 고정 PokeAPI 카탈로그를 사용한다. 특수 효과는 [Pokémon Showdown의 기술 정의](https://github.com/smogon/pokemon-showdown/blob/master/data/moves.ts)를 2026-09-17 확인해 직접 구현했다. 기존 게임은 단일 상태 필드를 사용하므로 동시에 여러 휘발성 상태를 가지는 완전한 원작 전투 시뮬레이터는 아니다. 방어·날씨·설치기·메가진화 등은 이번 범위가 아니다.

- Vitest: 특수 기술 회귀 10개와 기존 엔진 16개 통과. HP·단계·면역·대상·저장 복원 후 실제 행동 가능 턴을 검사했다.
- Rust: 랭크전 13개 통과. 로컬 PostgreSQL의 분리된 SQLx 테스트 DB에서 두 계정 매칭·턴 처리·두 리그 레이팅 분리를 포함한다.
- 배포 완료 여부는 이 문서가 아니라 GitHub Actions의 완료 상태와 운영 `/version.json`으로 판별한다.

알로라 변종 모델·메가진화는 별도 미완료 항목이다. 이번 변경에는 라이선스가 확인되지 않은 모델 파일의 신규 배포를 포함하지 않는다.
