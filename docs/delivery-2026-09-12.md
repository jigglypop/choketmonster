## AWS

기존 CLI 인증으로 계정 `960243570517`, 서울 리전에서 배포했다. 웹 스택은 `choketmonster-web`, 서버 스택은 `choketmon-server`다. EC2 `i-0edb04b57d4e1361b`의 `t3.small`과 비공개 RDS `choketmon-postgres`의 `db.t4g.micro` Single-AZ를 사용한다. 정적 파일과 서버 릴리스는 각각 비공개 S3에 보관하고 `/api/*`는 CloudFront VPC origin으로 연결했다. SSH·공개 DB·NAT·로드밸런서는 사용하지 않는다. API 캐시는 끄고 RDS TLS 인증서와 저장 암호화, 7일 백업을 적용했다.

FREE 정액 플랜은 VPC origin을 지원하지 않아 이 프로젝트만 종량제로 바꿨다. 기존 빈 WAF ACL도 CloudFormation으로 제거했다. 새 API 구성을 보존하도록 정적 배포 스크립트를 수정하고, VPC origin 사용 중 무료 플랜을 다시 켜는 작업을 차단했다. EC2 CPU는 `standard` 크레딧 모드로 초과 CPU 요금을 방지한다.

730시간 기준 EC2 $18.98 + RDS $18.25 = $37.23. 디스크, IPv4, 비밀 저장 등을 합친 예상 기본 운영비는 **월 약 USD 45~50**, 트래픽과 세금은 별도다. 실제 사용량과 청구서는 아직 한 달 관측하지 않았다. 공식 단가를 조회한 `artifacts/ec2-pricing.json`, `artifacts/rds-pricing.json`을 보존했다.

## 해석과 제한

로그인한 개체의 배틀 기술 결정에 전체 회로가 실제로 관여한다. 오픈월드 이동과 게스트 플레이는 기존 브라우저 128-node 회로를 사용한다. 화면의 신경망 그림도 브라우저 부분 회로이며 서버 전체 상태의 시각화가 아니다. 원본은 신경 연결 지도다. 감각 투영, tanh 동역학, 전달물질 부호 가정, 출력 readout, 보상 학습은 직접 설계했다.

기술 선택과 학습 갱신이 실행된다는 증거는 확보했지만 승률 개선은 입증하지 못했다. 일부 시드는 회복·상태 기술을 과도하게 선택했다. 회로 topology 자체를 학습시키거나 초파리의 생물학적 학습을 재현했다는 의미가 아니다.

초기 운영은 단일 EC2·Single-AZ DB와 두 계산 permit으로 제한한다. 계정당 저장 128슬롯·압축 64MB, 서버 신경 상태 512개 한도가 있다. 비밀번호 재설정·이메일 인증·서버 권위 전투 판정은 구현 범위에 포함하지 않았다. 로컬 포켓몬 PNG·GLB와 ROM은 배포 묶음에서 제외하고 기존 출처 CDN 사용 조건을 자산 문서에 유지했다. 기존 사용자 작업을 포함한 현재 작업 트리를 배포했으며 Git commit/push는 하지 않았다.
