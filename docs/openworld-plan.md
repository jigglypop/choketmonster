# 초켓몬스터 오픈월드 계획

2026-09-10 최신 요청에 따라 `gaesup-world` 기반 연속 오픈월드로 전환한다. 화면의 조작 캐릭터는 내 파트너 포켓몬이며 원통형 트레이너를 제거한다. 키보드·터치 이동과 카메라는 파트너의 실제 위치를 사용한다. 별도 트레이너 NPC와 체육관을 진행의 중심에 두지 않는다.

## 구현과 완료 조건

1. GaesupWorld, React Three Fiber, Rapier와 공개 Gaesup 런타임을 실제 연결한다. 카메라·이동 입력·공유 지형 높이/충돌 경계를 명시한다.
2. 초원·숲·호숫가·암석 구역을 연속으로 이동한다. 실제 내려받고 검증한 자연 소품과 애니메이션 포켓몬을 배치하고 브라우저에서 시각 품질을 확인한다.
3. 실제 MaleCNS 부분 회로가 개체의 이동·감각 반응과 자동 기술 선택에 쓰인다. 전투와 이동의 감각/행동 의미를 분리하며, 개체별 학습 기억과 재현 가능한 난수를 보존한다.
4. 월드 안에서 적 선택·접근·자동 전투를 진행한다. 네 기술 슬롯, HP·PP, 타입 상성, 레벨, 경험치·머니 보상, 포획·진화·회복·팀/박스와 151종 도감을 유지한다.
5. 위치, 등장 개체, 전투 상태, 신경 기억을 저장하고 같은 상태에서 복원한다. 렌더링은 시뮬레이션 난수를 사용하지 않는다.
6. GitHub `jigglypop/choketmonster`의 main에 작업을 올린다. AWS 전용 S3·CloudFront HTTPS 주소에서 빌드·자산·플레이 흐름을 검증한다.

## 배포 자산 경계

직접 제작한 지형과 배포가 허용된 자연 소품, 코드, 출처·검증 자료를 저장소와 배포 파일에 포함한다. 포켓몬 모델·스프라이트 원본 바이너리는 로컬 검증 캐시에 보존하고 공개 빌드는 고정한 원본의 공개 URL에서 읽는다. 저장소 코드의 MIT 조건을 포켓몬 자산의 재배포 허가로 해석하지 않는다.

## 현재 검증 기준

오픈월드가 기본 모험 화면이다. `src/openworld/panel.ts`가 `OpenWorldSimulation`을 실제 Gaesup runtime의 250ms system에 연결하고 `GaesupWorld` 장면에 위치와 배틀을 전달한다. 사용자 조작 준비 전에는 시뮬레이션을 진행하지 않는다. 배틀은 별도 화면으로 전환하지 않는다.

추가 요구인 포켓몬별 기술과 속도를 반영했다. PokéAPI에서 가져온 390개 기술의 종별 레벨업 목록·위력·명중률·PP·분류·우선도, 스피드와 상태 이상을 기존 배틀 엔진에 연결한다. 네 슬롯에서 수동 지정해도 같은 전투 정산 경로를 거친다. 수동 지시를 자동 정책의 학습 성과로 세지 않는다. 월드 이동에는 종족 스피드를 게임용 m/s로 변환하며, 전투 스피드와 구분해 표시한다.

자동 사냥과 지연 리젠을 기본 흐름에 넣는다. 가까운 적 선택 → 동행 개체 접근 → 자동 전투 → 경험치·머니 정산 → 4~6초 뒤 해당 생태계 개체 재등장이 반복돼야 한다. 리젠 대기와 자동 사냥 상태도 저장한다. 카메라를 뒤·위로 조정하고 좌우/상하 회전·줌·초기화 조작을 제공하며, PokéAPI 키 정보를 바탕으로 작은 종이 시야를 가리지 않도록 크기를 조절한다.

지면 접촉은 실제 지형 삼각형 표면과 현재 애니메이션의 스킨 정점으로 계산한다. 모델 전체에 적용하던 수직 흔들림을 제거하고 경사면을 따라 보간한다. 표시 크기는 애니메이션이 덮어쓰지 못하는 외부 Group에 적용한다. `scripts/verify-grounding.mjs`는 실제 GLB 8종의 대기/걷기/공격 576개 프레임을 지형 raycast와 독립 대조하고 포즈별 크기도 기록한다.

연속 월드 이동, 자동 전투의 경험치/머니/레벨 진화, 포획 후 개체 저장, 일시 정지와 리로드, 151종 검색, 모바일 화면을 브라우저 시나리오로 검증한다. 회로 동결·독립 기억·동일 체크포인트 재생·연결 절제와 기준 정책 비교는 `scripts/verify-openworld.ts`로 별도 확인한다. 이 검사는 게임의 모든 균형이나 생물학적 학습을 입증하지 않는다.
