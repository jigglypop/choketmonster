# 초켓몬스터 오픈월드 계획

2026-09-10 최신 요청에 따라 `gaesup-world` 기반 연속 오픈월드로 전환한다. 플레이어가 트레이너 역할을 맡는다. 별도 트레이너 NPC와 체육관을 진행의 중심에 두지 않는다.

## 구현과 완료 조건

1. GaesupWorld, React Three Fiber, Rapier와 공개 Gaesup 런타임을 실제 연결한다. 카메라·이동 입력·공유 지형 높이/충돌 경계를 명시한다.
2. 초원·숲·호숫가·암석 구역을 연속으로 이동한다. 실제 내려받고 검증한 자연 소품과 애니메이션 포켓몬을 배치하고 브라우저에서 시각 품질을 확인한다.
3. 실제 MaleCNS 부분 회로가 개체의 이동·감각 반응과 자동 기술 선택에 쓰인다. 전투와 이동의 감각/행동 의미를 분리하며, 개체별 학습 기억과 재현 가능한 난수를 보존한다.
4. 월드 안에서 적 선택·접근·자동 전투를 진행한다. 네 기술 슬롯, HP·PP, 타입 상성, 레벨, 경험치·머니 보상, 포획·진화·회복·팀/박스와 151종 도감을 유지한다.
5. 위치, 등장 개체, 전투 상태, 신경 기억을 저장하고 같은 상태에서 복원한다. 렌더링은 시뮬레이션 난수를 사용하지 않는다.
6. GitHub `jigglypop/choketmonster`의 main에 작업을 올린다. AWS 전용 S3·CloudFront HTTPS 주소에서 빌드·자산·플레이 흐름을 검증한다.

## 배포 자산 경계

직접 제작한 지형과 배포가 허용된 자연 소품, 코드, 출처·검증 자료를 저장소와 배포 파일에 포함한다. 포켓몬 모델·스프라이트 원본 바이너리는 로컬 검증 캐시에 보존하고 공개 빌드는 고정한 원본의 공개 URL에서 읽는다. 저장소 코드의 MIT 조건을 포켓몬 자산의 재배포 허가로 해석하지 않는다.

## 현재 검증 기준

기존 3D 필드 버전은 단위 테스트 36개와 브라우저 6개 흐름을 통과했다. 오픈월드 코어와 렌더러의 개별 검증은 통합 완료 증거와 구분한다. 최종 판정은 배포된 오픈월드의 이동 → 자동 전투 → 보상/포획 → 진화 → 저장/복원까지 확인한 뒤 한다.
