# 실험 하네스

## 명령과 출력

```powershell
npm run experiment -- --seeds 5 --train 100 --eval 20
npm run replay -- artifacts/experiment-실행시각/replay.json
```

`--out`으로 새 출력 폴더를 지정할 수 있다. 기존 파일은 덮어쓰지 않는다. `--graph data/local/circuit.json`을 전달하면 가져온 부분 회로를 같은 인터페이스로 평가한다. 기본 실행은 약 수 초이며 큰 회로는 더 오래 걸린다. CLI는 30개 뇌 시드, 시드당 학습 1,000회/평가 100회, 전체 30,000 에피소드 이하로 제한한다.

출력은 `report.json`, `report.md`, `brain-<seed>.json`, `training-<seed>.json`, `replay.json`이다. 리플레이는 정책 체크포인트로 전 과정을 다시 계산하고 모든 프레임과 종료 결과를 SHA-256으로 비교한다. 체크포인트에는 회로, 입력·출력 가중치, 순환 상태, 직전 특징/행동, 난수 상태가 포함된다. 새 에피소드에서는 순환 상태와 임시 학습 이력을 초기화하고 학습한 출력 가중치는 유지한다.

## 현재 과제

16×10 격자, 1개 열매, 5개 위험 칸, 240턴 제한이다. 시작 위치·위험·열매는 겹치지 않는다. 네 방향 이동 또는 쉬기를 선택한다. 열매를 먹으면 새 빈 칸에 생성되고 에너지를 회복한다. 위험 칸에 이동해 진입할 때 에너지가 감소한다. 위험 칸에 머무는 동안 계속 피해를 받는 모델은 아니다.

격자 과제 입력 12개는 상수, 목표 열매의 정규화된 x/y 방향, 방향 부호, 절대 방향, 인접 4칸의 위험/벽, 에너지이다. 배틀도 기존 체크포인트와 호환되는 12열을 유지한다. 앞 8열은 HP·레벨·속도·턴·상태이고, 뒤 4열은 각 기술의 PP와 공격 상성·면역, 회복 필요, 능력 단계 여유, 상태이상 적용 가능성을 합친 `[-1,1]` 신호다. `availableMoveMask`는 PP가 남은 네 기술과 대기 출력을 별도로 제공한다. 이 감각과 mask는 게임에서 설계했으며 생물의 감각 기관을 뜻하지 않는다.

보상은 매 턴 -0.04, 목표까지 맨해튼 거리 감소량 × 0.12, 열매 +3, 위험 진입 -1.5, 벽 충돌 -0.25이다. 특징 크기로 갱신량을 정규화한 선형 Q-learning 출력 갱신을 사용한다: 학습률 0.14, 할인율 0.85, 오차 [-4,4], 출력 가중치 [-12,12] 제한. 학습 중 ε=0.15, 평가 중 ε=0이다. 이는 구현상의 공학적 학습 규칙이며 도파민 회로를 재현한 규칙이 아니다.

## 비교 설계

- 뇌 시드: `42 + 97*i`. 합성 회로에서는 회로·입력 투영·초기 출력 가중치가 달라진다.
- 학습 맵: `10000 + 2000*i`부터 연속으로 생성.
- 평가 맵: `1000000 + j`. 학습 맵과 겹치지 않으며 모든 정책/뇌 시드에서 동일하다.
- 무작위 정책, 위험을 고려한 탐욕적 규칙 정책, 초기 출력 고정, 학습 후 출력 고정을 비교.
- 학습 후 정책은 초기 정책의 독립 복제본에서 학습. 평가 전후 출력 가중치가 동일함을 실행 중 확인.
- 규칙 정책은 참고 성능이며 최적 정책/상한은 아니다. 무작위/규칙 정책은 뇌 시드에 의존하지 않아 반복 행이 생긴다.

개별 평가 에피소드를 독립적인 학습 실행으로 세어 통계적 확신을 부풀리지 않는다. 뇌 시드별 평가 평균의 짝지은 차이와 시드 간 표준편차를 보고한다. 현재 보고서는 기술 통계이며 통계적 유의성 검정이 아니다. 이 평가 맵으로 모델을 조정한다면 이들은 개발용 맵이 되므로 새 확인용 맵을 따로 확보해야 한다.

## 완료 기준

코어 변경은 같은 체크포인트의 행동 재현, 평가 중 기억 불변, 개체별 격리, 유한한 상태를 확인한다. 정책/보상을 바꾸면 기존 결과를 보존하고 제한된 비교 실행을 새 폴더에 남긴다. 성능이 떨어진 경우 수치를 그대로 보고하며 코드 통과와 학습 성공을 분리한다. 기본 알고리즘과 결과를 바꾸지 않은 문구/CSS 변경 때문에 학습 실험을 다시 실행할 필요는 없다.

배틀 기술 선택은 공격·버프·회복·상태 기술을 모두 정책의 네 기술 출력으로 실행한다. 실제 HP 회복량, 적용된 능력 단계 수, 새 상태이상 적용 여부를 엔진 텔레메트리로 받아 보상에 넣는다. 이미 가득 찬 HP, 포화된 능력 단계, 면역 또는 이미 걸린 상태처럼 실행됐지만 전략 효과가 없던 변화 기술에는 작은 음의 보상을 준다. `Monster.moveLearning[moveId]`에는 선택·실행·효과 횟수와 누적 게임 보상을 저장할 수 있으며 그래프나 회로 상태를 복제하지 않는다.
