# 관동 오픈월드의 게임 보상

이 문서의 보상은 커넥톰 기반 정책의 출력층을 학습시키기 위해 직접 설계한 수치다.
생물학적 도파민의 측정이나 초파리의 보상 회로를 재현한 결과가 아니다. MaleCNS
부분 회로는 recurrent topology와 연결 가중치를 제공하고, 감각 입력·행동 대응·이
보상 함수·Q-learning 갱신은 게임 구현이다.

## 이벤트별 보상

`src/game/rewards.ts`는 개체 ID와 항목별 내역을 포함한 `EngineeredReward`를
반환한다. 합계는 매 이벤트 `[-2, 2]`로 제한한다.

| 이벤트 | 값 | 조건 |
| --- | ---: | --- |
| 조우 참여 | `+0.12` | 이동 행동이 실제 조우 시작으로 전환된 한 번만 적용 |
| 상대 HP 감소 | 감소한 상대 최대 HP 비율 `× 0.9` | 한 턴에 `0..0.9` |
| 자기 HP 감소 | 감소한 자기 최대 HP 비율 `× -0.75` | 한 턴에 `-0.75..0` |
| 유리한 공격 타입 선택 | `+0.18` | 실제 실행되어 적중한 공격 기술의 타입 배율이 1보다 큼 |
| 불리하거나 무효인 공격 타입 선택 | `-0.12` | 실제 실행되어 적중한 공격 기술의 타입 배율이 1보다 작음 |
| 회복 성공 | 회복한 최대 HP 비율 `× 0.65` | 실제 회복량만 반영 |
| 능력 단계 변화 | 적용 단계당 `+0.08`, 최대 3단계 | 상한·하한에서 변화가 없으면 성공으로 세지 않음 |
| 새 상태이상 적용 | `+0.18` | 면역 또는 이미 상태가 있으면 적용으로 세지 않음 |
| 효과 없는 변화 기술 | `-0.12` | 적중·실행됐지만 회복·단계·상태 효과가 하나도 없을 때 |
| 승리 / 패배 | `+1.0` / `-0.8` | 종료 이벤트 한 번 |
| 레벨 상승 | 레벨당 `+0.25`, 최대 2레벨 | 경험치를 받은 해당 개체만 |
| 진화 | `+0.45` | 진화한 해당 개체만 |

대기, 같은 상태를 다시 읽는 tick, 실행되지 않은 기술에는 기본 보상이 없다. 타입
보상은 공격자의 종 타입으로 추측하지 않고 그 턴에 선택·해결된 기술 타입과 현재
방어자 타입으로 계산한다. 변화 기술, 빗나감, 행동 불능, 선행 기절 등으로 공격이
실행·적중하지 않았다면 타입 보상도 주지 않는다.

## 학습 자격과 개체 격리

helper는 보상 수치와 별도로 `learningEligible`을 반환한다. 이 값은 전역 학습
스위치가 켜져 있고 `decisionSource === 'connectome'`일 때만 참이다. 수동 선택과
fallback 행동의 결과는 화면·평가 지표로 집계할 수 있지만 그 행동을 커넥톰 정책의
선택으로 잘못 강화하지 않는다. 호출자는 `learningEligible`이 참일 때만
`ConnectomeController.choose`의 다음 reward 또는 `finish`에 합계를 전달해야 한다.

보상은 `individualId`와 함께 계산한다. HP 변화, 승패, 레벨 상승과 진화는 해당
턴에 행동하고 경험치를 받은 개체에만 귀속한다. 팀 교체나 선두 변경 뒤 다른
개체의 `BrainState.previous`, readout 또는 업데이트 횟수에 보상을 전달하면 안 된다.
레벨 상승량은 전투 직전과 직후에 같은 `instanceId`를 조회해 계산하며, 이상한사탕
사용처럼 전투 밖에서 일어난 성장은 이 전투 보상에 넣지 않는다.

저장 스냅샷은 `rewardLedgers[instanceId]`에 개체별 `RewardLedger`를 둘 수 있다.
각 ledger는 `rewardModel`, `individualId`, 최근 32개 이벤트, 평생 이벤트 종류별
횟수, 구성요소별 합계·횟수와 전체 합계를 저장한다. 최근 항목에는 event, tick,
선택 출처, 학습 자격, 합계와 breakdown이 들어간다. `appendReward`는 이전 객체와
배열을 수정하지 않고 새 ledger를 반환하며, 구성요소 합계는 절댓값 10억, 개별
횟수도 10억 이내로 제한한다. ledger는 그래프와 BrainState를 복제하지 않는다. 실제 학습
상태의 근거는 여전히 각 개체의 `brain.updates`와 readout 가중치다. ledger 합계
자체를 생물학적 학습 증거로 사용하지 않는다.

각 `Monster`는 선택적으로 `moveLearning[moveId]`에 선택 횟수, 실제 실행 횟수, 피해 또는 전략 효과가 난 횟수, 누적 게임 보상을 저장한다. 이 통계는 개체와 함께 직렬화되며 기술 선택을 관찰하기 위한 기록이다. 가중치 변화의 근거는 계속 `brain.updates`와 readout이고, 통계가 증가했다는 사실만으로 학습 성공을 주장하지 않는다. 기존 reward ledger에는 `moveEffect: 0`을 채워 읽는 호환 migration을 적용한다.

## 오픈월드 통합 계약

조우 직전에는 조우로 이어진 이동의 개체 ID와 선택 출처를 보존하고
`rewardEncounter`를 한 번 호출한다. 전투 턴 직전에는 양쪽 활성 개체의 HP·최대 HP,
레벨, 실제 해결될 기술 타입과 방어자 타입을 보존한다. `actBattle` 직후 같은 개체의
HP와 결과를 비교하고, 레벨 상승 및 진화 이벤트를 그 ID에 더해
`rewardBattleTurn`을 호출한다.

수동 기술 선택 전에는 기존 pending learning history를 지우고, helper 결과가 양수여도
정책을 업데이트하지 않는다. `learning=false` 평가에서도 보상 합계는 관찰할 수
있지만 readout과 `updates`는 시작 체크포인트와 같아야 한다. 통합 뒤에는 같은 초기
정책·월드·시드에서 무작위 또는 학습 전 정책과 학습 정책을 비교하고, 고정 평가
동안 가중치 불변과 저장 리플레이 재현을 별도로 확인한다.

## 2026-09-11 통합 검증

`scripts/verify-kanto-rewards.ts`는 학습 시드 921001·921100에서 각 24전만 학습하고, 미사용 시드 923001·923100으로 무작위·학습 전·학습 후·연결 가중치 제거 조건을 비교한다. 파이리 Lv15의 불꽃세례·물대포·몸통박치기·울음소리와 뚜벅쵸/꼬마돌 Lv12를 사용한 좁은 과제다. 매 전투 전 HP·PP·레벨·활성도를 같은 값으로 되돌리며 전투 중 회복은 없다. 후보는 실험 파일에만 남기고 플레이어의 기존 뇌를 덮어쓰지 않는다.

`artifacts/kanto-rewards-2026-09-11T12-10-01-267Z/report.json`에서 평균 보상은 무작위 1.2083, 학습 전 0.4418, 학습 후 1.7767, 연결 제거 1.4963이었다. 평균 타입 보상은 각각 -0.15, -0.15, 0.105, -0.06이다. 학습 후 4전 모두 승리했고 무작위도 4전 모두 승리했으므로 일반적인 승률 우위를 주장하지 않는다. 연결 제거는 모든 조건의 활성도와 일부 행동 추적을 바꿨고, 같은 행동이 나온 평가도 있다.

평가 중 양쪽 뇌의 가중치와 업데이트 횟수 불변, 학습 중 실제 업데이트, 개체 상태 격리, 전투 첫 턴 이후 저장한 체크포인트의 정확한 후속 리플레이를 확인했다. `checkpoint.json`, `replay.json`, 개체별 후보 뇌와 해시가 같은 폴더에 있다. 수동 승리와 공유 경험치 레벨업은 보상 기록을 남기되 양쪽 소유 개체의 가중치를 바꾸지 않는 통합 테스트도 통과했다. PP가 없어 다른 기술로 대체된 출력도 정책이 직접 선택한 행동으로 강화하지 않는다.
