# 실제 커넥톰 연결 이후

이전 문서의 ‘실제 부분 회로 한 개 연결’은 MaleCNS v1.0의 128개 뉴런·3,623개 연결로 진행했다. 원본·선택 근거는 [connectome-source.md](connectome-source.md), 회로 절제·재현 근거는 [game-neural-evidence.md](game-neural-evidence.md)에 있다. 현재 게임 완료 범위는 [delivery-plan.md](delivery-plan.md)를 따른다.

추가 연구가 요청될 때만 다음 중 필요한 부분을 진행한다.

- 같은 배틀 조건에서 학습 초기·학습 후·무작위·규칙 정책을 비교한다. 독립 학습 시드와 평가 가중치 고정을 유지한다.
- 실제 세포형을 근거로 입력과 출력을 제한하고 현재 무작위 투영과 비교한다.
- 회로 크기별 계산 시간·메모리를 측정한 뒤 전체 뇌 또는 더 큰 부분 회로의 범위를 정한다.

공개 원본 다운로드와 로컬 구현·제한된 실험은 별도 승인 없이 진행할 수 있다. 비용·계정 접근·외부 배포가 필요한 시점에는 그 작업을 제외한 결과를 먼저 완성한다. 전체 뇌나 생물학적 학습을 이미 구현한 것으로 표현하지 않는다.
