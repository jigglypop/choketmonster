# 합성 모형의 첫 비교 결과

실행일: 2026-09-10. 실행 명령:

```powershell
npm run experiment -- --seeds 5 --train 100 --eval 20 --out artifacts/baseline-v1
npm run replay -- artifacts/baseline-v1/replay.json
```

뇌 시드 42, 139, 236, 333, 430. 각 100회 학습 후 별도 지도 20개에서 평가. 모든 평가에서 학습 비활성화. 같은 지도를 조건끼리 공유한다.

| 정책 | 평균 열매 | 평균 위험 진입 | 평균 누적 보상 |
|---|---:|---:|---:|
| 무작위 | 0.55 | 4.15 | -17.48 |
| 규칙 기반 | 7.90 | 0.00 | 22.99 |
| 학습 전 고정 | 0.10 | 0.47 | -45.90 |
| 학습 후 고정 | 2.72 | 0.12 | 0.39 |

학습 전 대비 열매 평균 차이 +2.62개. 5개 뇌 시드 모두 양의 차이를 보였다. 학습 후 개별 평균은 1.90, 1.75, 4.60, 2.65, 2.70개였다. 규칙 기반 정책의 성능에는 미치지 못했다.

리플레이는 241개 프레임(초기 상태 포함)의 일치를 확인했다. 프레임 SHA-256:

```text
4c888a90fd22dce5b1868a10e9395689e69af039e5709b9d8375caf61783440e
```

이 결과는 **합성 신경망 + 직접 설계한 감각 입력 + 거리 보상 + 학습 출력층**의 조합에 대한 기술 통계다. 연결 구조의 생물학적 의미, 전체 뇌 재현, 무보조 탐색, 전투 전략, 생물의 학습을 입증하지 않는다. 회로 특징 없이 감각만 쓰는 절제 비교도 아직 없다. 초기 정책이 벽에서 멈추는 경우가 있어 보상 차이만 강조하면 성능이 과장될 수 있으므로 열매와 위험 접촉을 함께 기록했다.

현재 로컬 근거는 `artifacts/baseline-v1/report.json`, 정책 체크포인트, 학습 이력, `replay.json`이다. 큰 실행 산출물은 기본적으로 버전 관리에서 제외하며 이 요약은 저장소에 남긴다.
