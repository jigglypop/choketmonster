# 장착 도구 확장과 밸런스

장착 도구를 6종에서 47종으로 늘렸다. 메가진화석 64종을 더해 장착 가능한 물품은 111종이다. 새 도구 41종의 효과는 클라이언트 전투 엔진(`src/game/engine.ts`, `src/game/battle.ts`)과 서버 랭크 엔진(`rust-server/src/ranked.rs`)에 같은 규칙으로 구현했다. 기존 6종의 효과는 바꾸지 않았다.

## 데이터

- `src/data/field-items.json`의 장착 도구 행에 `tier`(`common`·`uncommon`·`rare`)와 `category`(`battle`·`berry`·`support`)를 넣었다. 이름·등급·분류는 이 파일 하나에서 관리한다. Rust 저장 검증은 이 파일에 있는 id를 모두 가방 키와 장착값으로 받는다.
- 포획 확률(`HELD_TOOL_CAPTURE_RATES`), 길가 가중치(`HELD_TOOL_PICKUP_WEIGHTS`), 출처 종(`HELD_TOOL_SOURCE_FAMILIES`)은 `src/openworld/field-item-drops.ts`에 있다. 가격은 `HELD_TOOL_TIER_PRICES`(engine.ts)에서 등급별로 정한다.

| 등급 | 포획 1회당 확률 | 길가 가중치 | 가격 |
| --- | --- | --- | --- |
| 일반 (21종) | 15% | 4 | 2,000원 |
| 고급 (15종) | 8% | 2 | 4,000원 |
| 희귀 (11종) | 4% | 1 | 6,000원 (생명의구슬만 8,000원) |

- 포획 보상은 실제로 포획했을 때만 추첨한다. 처치만 하면 지급하지 않는다. 난수는 한 번만 뽑고, 한 번에 최대 1개를 준다. 출처가 겹치는 종(나옹·페르시온: 구애스카프와 부적금화)은 두 확률을 합친 범위에서 하나만 나온다. 메가진화석 규칙(종마다 총 4%, 모습이 여러 개면 균등 분배)은 그대로 둔다.
- 길가 물품은 지방마다 12칸, 10분 재생성이다. 이전 저장의 30분 대기는 불러올 때 10분으로 줄인다. 칸의 종류는 기존처럼 해시로 메가진화석 25%, 도구 75%를 정한다. 도구는 먼저 등급 가중치로 물품을 고르고, 그다음 그 물품이 놓일 수 있는 길가 지점을 고른다. 도구 하나가 나올 확률은 일반이 희귀의 4배, 고급이 희귀의 2배다.
- 상점에서는 여전히 팔지 않는다. 필드 획득과 플레이어 간 금전·물품 거래로만 얻는다. 기존 세이브에 없는 가방 키는 불러올 때 0으로 채운다.
- 기존 도구의 변경: 포획 확률 12% → 4%(희귀), 먹다남은음식·기합의띠 가격 4,000 → 6,000원.

## 전투 규칙

- 한 번 쓰는 도구(기합의띠, 열매 3종, 하양허브, 약점보험, 풍선)는 기존 `battle.consumedTools`에 개체 id를 남겨 그 전투에서만 효과를 끈다. 도구 자체는 사라지지 않는다. TS와 Rust 저장 검증 모두 이 목록에 소모형 도구 장착 개체만 허용한다.
- 선제공격손톱과 기합의머리띠의 확률은 지닌 개체가 있을 때만 엔진 난수를 추가로 뽑는다. 그래서 도구가 없는 전투의 난수 흐름은 이전과 같다. 랭크전은 기존처럼 결정적 해시 롤을 쓴다.
- 팀 상세의 도구 선택은 장착 도구 / 열매 / 보조 / 메가진화석으로 묶어 보여준다. 재고가 0이면 비활성화하고, 장착한 도구의 효과를 선택 칸 아래에 한 줄로 표시한다.
